# 审核与发布流程
- 场景 9：四个审核 Agent 依次给出理论、证据、教学、表达建议；“定位正文”可手动查看目标段，四条都是可选建议。
- 场景 10：采用证据建议，保留教学建议后仍能提交审核，状态明确记录保留项不阻塞提交。
- 场景 11：管理员退回具体批注；“让 AI 处理”仅生成待确认修订和回复草稿，接受修订后仍须手动标记批注已解决。
- 场景 12：管理员通过并发布，检索卡显示固定版本 v1.0，DOCX 导出指向该固定版本。
- `?scene=check`、`?scene=submit`、`?scene=comment`、`?scene=publish` 可直达四个场景；无参数默认 `check`。顶部场景按钮会同步 URL，并重置为该场景独立状态。
- 每个场景支持播放、暂停、重播、下一步和建议卡中的手动操作。
