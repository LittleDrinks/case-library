# 资料流程
- `?scene=scope`、`?scene=search`、`?scene=web`、`?scene=materials` 分别直达场景 5–8；无参数默认场景 5，点击场景卡会同步更新 URL。
- 场景各自保留进度；切换后可分别播放、暂停、重播或“执行下一步”，每段 14–16 秒。
- 场景 5 的四项复选框可直接调整本次授权，AI 检索上下文、正文引用、附件与边界说明立即更新；重播会恢复动画默认范围。
- 场景 5 显示资料工具受本次理论知识、平台案例与素材、联网检索、网页采集勾选限制；场景 6 分流知识、案例与素材，案例只进正文引用。
- 场景 7 提交 URL 后将网页副本写入附件；场景 8 在素材掌控台筛选并把平台素材挂载到当前案例附件。
