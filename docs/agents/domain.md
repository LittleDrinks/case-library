# Domain docs

本仓库采用单一领域上下文（single-context）。领域词汇与架构决定的维护遵循根目录 `AGENTS.md` 第 6 节。

## 何时读取

- 开始调查或实施时，读取目标 issue、实施规格和相关 Wayfinder 决定，核对适用于当前范围的术语与约束。
- 根目录 `GLOSSARY.md` 存在时，读取相关条目，并在代码、测试和票据中沿用其词汇；不存在时直接继续，不因缺少词汇表阻塞任务。
- 修改受架构决定影响的行为前，通过 GitHub Issues 和 Wayfinder 读取相关 ADR 及后续替代决议；本地不保留 ADR 文档。

## 维护约定

- 使用 `domain-modeling` 讨论术语或记录 ADR 前，读取其 `SKILL.md`；产物位置按项目规则确定。
- 产品规划、规格、QA 和 ADR 的发布位置由 `AGENTS.md` 第 6 节规定；本配置只提供读取入口。
- 发现术语或方案与当前决定冲突时，说明冲突和实际影响；规则改变时在权威票据中链接替代决议。
