# 设计决策
## 工作台
- 案例创作与审核共用画布工作台。ProseMirror 文档 JSON 是正文唯一真源；DOCX 只作固定版式导出件。
- 桌面端以正文画布为主，配合浮动大纲与 AI、批注、附件辅助面板；移动端正文单栏，辅助面板进入抽屉。
- AI 的写作结果先作为候选展示，教师确认后才修改正文；批注锚定选区原文与所在小节，正文变动后按原文渐进重挂。
- 提交冻结正文、附件和被引用案例版本；审核通过发布该快照，已发布案例在工作台只读。
## 资源与图谱
- 资源检索统一展示案例、知识和素材；空查询用于浏览，关键词查询按相关度与发布时间排序。筛选按内容类型收敛，分面计数基于当前查询、权限和其他筛选条件。
- AI 摘要仅在本地结果不足或问题式查询时生成；其他检索直接呈现命中结果。
- 图谱是检索结果的关系视图，不承担复杂分析。它展示当前可见资源、检索词和共同主题；节点按类型区分，点击资源节点显示详情入口，节点可拖动。
- 图谱布局由 `d3-force` 的连接、斥力、碰撞和居中力共同计算；SVG 绘制关系线，HTML 按钮承载节点和交互。
## 内容流转
- 案例由正文、案例附件、批注和版本组成。网页采集和上传文件先成为私有案例附件，发布后投影为素材；素材始终追溯来源案例版本与附件。
- 同一规范化 URL 或内容指纹形成一条素材，多个来源以挂载关系聚合；新增挂载不覆盖既有访问级别。
- 管理后台以表格管理审核、发布、素材、类型与模板、账号和公告；审核意见与通过、退回、要求补充等动作绑定。
## 视觉语言
- 界面使用上大红 `#BA1C22`、暖灰纸底 `#F6F4EF` 和白色内容面；红色用于主要动作与关键信息，语义色只表达状态。
- 导航、按钮、表格和标签使用无衬线字体；案例、教材、引用副本和标题使用宋体回退链。
- 正文、引用副本和详情阅读区保持纸张式内容面与克制阴影；管理和审核界面以表格和状态标签优先。
- 页面不出现功能原理说明或营销式标语；交互以状态反馈、悬停操作和必要的淡入过渡为主。
