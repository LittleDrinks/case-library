# ADR 0007：检索页去凌乱——目录式列表 + 百度式高级筛选

状态：已定案（2026-07-21 grilling 会议，同日两轮迭代后收敛）

## 背景

用户反馈「资源检索界面有点凌乱」。第一轮改造（混合结果流 + 极简条目 + 范围下拉 + 分面按页签收敛）落地后实测仍「效果并不是很好」，根因被进一步确认为：

1. **检索与探索没有分开**：落地态的杂志式精选板块（已发布案例 4 条 / 知识章节入口 / 最新素材 8 条）既不是准确搜索，也不是完整列表——用户「随便翻翻」时翻不到全部资源。
2. **筛选形态不对**：左栏分面 + 搜索框范围下拉不符合用户心智，用户明确要求「百度高级搜索那种感觉，可以多选，有下拉框」。

## 决策

核心模型：**浏览 = 不带关键词的检索**。检索页只有一个目录式列表，模式完全由搜索框是否有词推导，无显式模式切换。

1. **目录式列表（空查询即浏览）**
   - 打开检索页 = 全量资源的统一列表（案例/知识/素材合并，「全部」页签），默认最新排序，10 条/页分页到底；这就是「随便翻翻」的完整列表。
   - 输入关键词回车 = 同一列表变为按相关度排序的搜索结果；清空关键词回到目录。
   - 杂志式精选板块**砍掉**（不挪首页）。
2. **「全部」页签 = 单一混合结果流**：三类合并排序分页（检索态按 score，目录态按最新）；条目共用极简格式——小字类型标（案例/知识/素材）+ 标题 + 90 字摘要，其余徽标/标签云/命中理由全砍。
3. **百度式高级筛选**：页签行右侧一行筛选下拉框，下拉内 checkbox 多选；选中条件以 chip 行回显（可单个移除、可清空）；左栏分面栏取消。
   - 维度按页签出项：全部 = 标签 + 更新时间；案例 = 案例类型/学段/标签/更新时间；素材 = 可信度/公开范围/标签/更新时间；知识 = 更新时间（知识条目的时间口径 = 所属教材来源的 updatedAt）。
   - 更新时间 = 单选（不限/一周内/一月内/一年内）；其余维度多选。
   - 选项计数沿用 ADR 0004 的结果集口径（当前查询 + 其他筛选下的计数）。
4. **范围页签保留**（全部/案例/知识/素材，带计数，置于搜索框下方结果区顶部）；**搜索框上的范围下拉删除**（第一轮加了，本轮按百度模型撤掉）。
5. **排序**：目录态隐藏「综合排序」（无关键词时无相关度），各页签出项退化为——全部 = 最新；案例 = 最新/点赞；素材 = 最新/被引；知识 = 教材顺序。检索态维持 ADR 0004 的出项。
6. **保留**：「已扩展检索」提示行、AI 回答块（ADR 0004 规则，仅检索态出现）、列表/图谱视图切换、单类型页签分页。

## 后果

- `pages-browse.js` 的 `P.search` 重构：落地态杂志板块删除，目录态复用结果列表渲染（空查询 + 默认最新排序）；新增筛选下拉组件（多选 + 单选两种）与 chip 行；新增少量 CSS（下拉面板、chip）。
- ADR 0004 的「页签联动隐藏分面组」决策被本轮的「筛选下拉按页签出项」取代；分面计数口径决策仍然有效。
- 时间筛选对知识条目按教材来源时间一刀切（要么全过要么全不过），语义上可接受：时效筛选本就面向案例与素材。

## 明确不做

- 不做杂志式落地板块的任何保留形式（不挪首页、不折叠）。
- 不做时间筛选的自定义日期区间。
- 不在目录态提供「综合排序」。
- 不在筛选下拉外再保留左栏分面或搜索框范围下拉。
