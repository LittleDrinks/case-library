# ADR 0007：目录检索与高级筛选
资源检索以空查询作为浏览入口，案例、知识和素材共用一条结果流，每页 20 条并使用游标前后翻页；关键词查询按相关度和发布时间排序。页签为全部、案例、知识、素材，计数口径为当前查询与访问权限下的各类总数。全部页提供标签和时间筛选，案例页提供管理员目录标签和时间筛选，素材页提供信源等级、类型、标签和时间筛选，知识页不提供筛选。
标签支持按名称查找和按目录浏览，管理员新增选项直接出现；目录层级不决定匹配逻辑。普通页面默认全部符合（AND），可切换任一符合（OR）；后端另支持 Agent 使用的混合条件。标签数量按当前可见结果计算，包含全部已选条件，OR 模式下不是加入后的总数，零计数标签仍可选择。
筛选使用页签右侧下拉与可删除条件标签。页面保留 AI 摘要、列表和图谱；登录后的素材掌控台另用左侧条件栏处理工作视图、来源权威性、素材类型和对外使用范围。
