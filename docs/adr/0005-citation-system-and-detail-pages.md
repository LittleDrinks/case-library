# ADR 0005：引用体系与三类详情页

状态：已定案（2026-07-19 grilling 会议）

## 背景

引用原来只是右侧面板里的清单卡片：与正文无互跳、无操作、编号顺序与正文出现顺序无关。用户判定「引用卡的设计本身有问题」，并要求「word 编辑区把引用独立出来」；素材的引用入口则定为「复制 ID 丢给 Copilot」而非专用按钮。

## 决策

### 1. 引用独立：文末自动参考文献区

- 正文中引用处插〔n〕上标标记；文档末尾自动生成「参考文献」区，列出引用的教材节/素材。
- 参考文献区不可手工编辑，随引用增删自动更新；导出 Word 时带上。
- 编号〔n〕按正文出现顺序自动重排。
- 工作台右侧「资料」页签专注素材的查找/挂接，不再承担参考文献展示。

### 2. 引用卡改造（审核页与详情页共用）

- 每条引用支持操作：定位正文引用处 / 查看素材或教材节详情 / 取消引用（作者模式）。
- 正文上标与右栏引用卡双向互跳。

### 3. 案例详情页（公开页）

- 左侧目录 TOC（小节目录，点击定位，滚动高亮当前节）。
- 嵌局部引用关系图（ADR 0004 的 ego 模式）。
- 操作：点赞、收藏、复制链接、导出 Word。
- 「结合案例备课」生成入口：任何登录用户可生成教学设计/讨论题/PPT 提纲；生成物归生成者个人，存入其「我的案例」页的备课材料区块，不随原案例发布。
- 相关案例推荐增强：同类型 + 同学段 + 共享引用，至少 3 条。

### 4. 素材详情页

- 使用度展示：被引次数 / 最近被引时间 / 待淘汰标（ADR 0003）。
- 可信度分级视觉：权威来源 / 一般来源 / 待核实 三档不同层级展示并说明依据。
- 时效提示：政策文件类发布超过 3 年显示「注意时效性」；提供「重新采集」更新内容副本。
- 「复制引用 ID」按钮：复制素材 ID（如 m-kcsz），用户粘贴到工作台 Copilot 输入框即把该素材加入当前案例引用；不做「引用此素材」跳转按钮。

### 5. 知识点详情页（教材）

- 右栏加「被引用于」：列出引用该节的案例。

## 后果

- 文档 blocks 模型新增文末参考文献区渲染规则（由引用数据派生，不落库为 blocks）。
- Copilot 输入需识别 `m-xxx` / `kn-xxx` 形式的 ID token 并转为引用动作。
- 收藏需要新的用户级数据结构（`db.favorites`）。

## 明确不做

- 不做「引用此素材」页面跳转式按钮。
- 备课生成物不共享、不挂到原案例公开页。
- 参考文献区不做手写编辑。
