# 术语表（grilling 2026-07-19 定稿）

## 角色与界面

- **作者模式**：工作台的默认形态，文档可编辑，面向案例作者。
- **审核模式**：同一工作台的只读形态 + 审核动作区，面向案例管理员；与作者模式共享文档渲染、批注面板、Copilot。
- **工作台**：案例的编辑界面，三个页签（Copilot / 批注 / 资料）+ 文档编辑区。

## 批注体系

- **批注**：平台所有反馈的统一载体。锚定方式为「选区原文（quote）+ 所在小节」，来源包括 AI 审校、提交前自检、人工（审核员/作者）。
- **选区锚定**：在正文选中文字后浮出「+ 批注」，批注记录选区原文。
- **模糊重挂**：正文被改写后，按 quote 前缀渐进匹配重新定位批注；失败时展示原文快照并标「原文已变动」。
- **批注线程**：同一条批注下的追加回复序列（作者回应、审核员追问/确认），跨提交轮次保留。
- **批注即意见**：审核动作「退回/要求补充」必须至少挂一条批注；总评可选。
- **候选批注**：AI 审校产出、尚未挂载的批注草稿，由人勾选后生效。

## 版本与审核

- **工作版本**：案例提交前的可编辑状态；保存 = 在工作版本内保存。
- **版本号**：每次提交冻结生成的新版本（v1、v2…）；审核针对版本快照。
- **冻结**：提交后到审核结束前案例不可编辑；开始审核前作者可撤回。
- **撤回**：开始审核前作者收回提交，回到工作版本继续编辑。
- **版本对比（diff）**：重新提交后，上一版与本版的文字级增删高亮。

## 引用体系

- **〔n〕上标**：正文中的引用标记，编号按正文出现顺序自动重排。
- **参考文献区**：文档末尾自动生成的引用清单，不可手编，随引用增删更新，导出 Word 时带上。
- **引用卡**：展示单条引用的卡片（支持定位/查看详情/取消引用）。
- **复制引用 ID**：素材详情页复制素材 ID（m-xxx），粘贴到 Copilot 输入框即完成引用挂接。
- **局部引用关系图（ego 图）**：以单个案例为中心的两跳关系图（引用了什么 + 谁引用了它），嵌入案例详情页与资料页签。

## 素材生命周期

- **被用**：素材被案例正文引用（进入引用清单）；浏览不计入。
- **待淘汰**：满 30 天未被引用的素材自动获得的标记；管理员每月人工确认清理，可豁免。
- **查重双闸**：采集素材时先做 URL 查重，再做相似度查重（top-3 相似素材提示复用）。
- **使用度**：素材的被引次数与最近被引时间。

## 文件与密级（ADR 0009）

- **素材**：教学参考文件与链接（学习资料、政策文件、教师上传），可上传、可删除/停用、按密级管理（ADR 0011 分层定义）。
- **知识**：教材的结构化章节（章→节），构建期从教材文件派生导入，不经素材管道；管理入口在管理后台「知识管理」页签（ADR 0011）。
- **真实文件**：素材挂载的原始文件副本，服务端 `files/` 落盘，素材详情页可在线预览/下载。
- **种子素材**：随站点预置的素材（中心组学习资料 69 期），只能停用，不能删除。
- **上传素材**：经管理后台上传入口创建的素材，文件与记录权威在服务端 `files/index.json`，admin 可删除。
- **三级密级**：素材 level 0 公开 / 1 校内 / 2 受限；用户 `maxLevel` 为可用上限，文件列表与下载由服务端强制（与前端 `canSeeMaterial` 同口径）。
- **演示 token**：页头切换账号即登录，服务端签发的 HMAC 令牌（12h 有效），写操作与越级读取的校验凭据；无密码，完整账号体系归正式栈。
- **教材主页**：`#/book`，知识层级的教材入口——教材信息 + 章节目录 + 原始文件切片，`#/book?sec=<结构路径>` 深链（ADR 0011）。

## 派生切片（ADR 0010）

- **派生切片**：由切块规则从真实文件自动派生的标题树节点；文件是唯一数据源，切片不是另一份手工维护的数据。
- **切块规则**：按 `#{1,3}` 标题行切分；出现的标题级别按 # 数排序为第 1..K 层；不合并、不二次切分；前端 `U.chunkMd` 与 `build_data.py assign_file_secs` 同规则，52/52 一致性验收。
- **结构路径**：切片的层级地址，各级序号拼接（缺层不占位），如教材 `2.1.1`（章.节.目）、学习资料 `1.4`（栏目.篇）；深链 `#/material/<id>?sec=<路径>` 直达。
- **知识坐标与文件坐标同构**：kn 节（如 kn-01-02）与教材文件切片（如 `1.2`）经 `fileSec` 锚点一一对应，知识详情页可跳到「教材此节」。

## 检索与图谱

- **分面计数**：筛选项后的数字，口径 = 当前查询 + 其他筛选下的结果集计数（ADR 0007 起呈现在筛选下拉的选项内）。
- **问题式查询**：含「哪些/怎么/为什么/如何」或为长句的检索词；只有问题式查询或本地结果不足时才自动生成 AI 回答。
- **骨架+案例模式**：全库力导图的默认装配——只画教材章节骨架与案例节点，素材点开案例后再展开。
- **混合结果流**：检索后「全部」页签的形态——案例/知识/素材合并为单一列表按相关度排序分页（ADR 0007），替代旧的三分组堆叠。
- **目录式列表**：检索页空查询时的形态——全量资源的统一列表，默认最新排序、分页到底；浏览 = 不带关键词的检索（ADR 0007）。
- **高级筛选下拉**：页签行右侧的一行筛选下拉框（百度高级搜索式），下拉内 checkbox 多选，选中条件以 chip 行回显；维度按页签出项（ADR 0007）。

## 首页与推荐

- **动态卡**：首页的三张卡片——平台增量动态 / 时政新闻流 / 平台公告。
- **时政新闻流**：经 web-search 抓取的思政/高教新闻列表，本轮只读跳原文，不入库。
- **我的备课材料**：在案例详情页生成的教学设计/讨论题/PPT 提纲，归生成者个人，存于「我的案例」页。
