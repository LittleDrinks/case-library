# ADR 0004：资源检索页与知识图谱

状态：已定案

## 背景

检索页同时支持案例、知识和素材浏览；分面计数、筛选和排序按资源类型及当前查询联动。AI 摘要解释检索意图与可用资源，知识图谱承接可视化定位。

## 决策

### 1. 检索页

- 标签计数包含当前查询、权限和全部已选条件，表示当前结果中具有该标签的数量；OR 模式下不作为加入后的总数，零计数标签仍可选择。
- 页签联动：切到某类内容时隐藏无关分面组（如「知识」页签隐藏案例类型/素材可信度）。
- 排序按页签出项：案例 = 综合/最新/点赞；素材 = 综合/最新/被引次数；知识 = 综合/教材章节顺序。
- 已登录且模型可用时，每次非空检索成功并返回可见结果后自动生成 AI 摘要，普通短关键词同样生成。空查询浏览与无结果不调用模型；先呈现结果列表，再流式展示摘要。
- 摘要默认展示部分内容，可展开全文并收起；摘要与引用对应本次检索结果，新的检索结果不得被旧回答覆盖。
- AI 回答缓存（同词复用）：原型阶段不做，以后再说。
- 检索页对所有用户只读；管理动作不并入检索页（改回后台表格，见 ADR 0006）。

### 2. 知识图谱

- 从导航撤下，并入检索页：顶部「列表 / 图谱」视图切换，检索词上下文带入图谱（命中节点高亮）。
- 全库图保持轻量展示定位：默认只画教材骨架（章/节）+ 案例节点；素材不单独成点，点开案例节点时以它为中心展开其引用。
- 节点交互：单击出信息浮卡（标题/类型/摘要/「打开」），双击直达详情页。
- 局部引用关系图：以某案例为中心的两跳图（引用了什么 + 谁引用了它），嵌入案例详情页与工作台资料页签。

## 后果

- 导航收敛为四项（首页/我的案例/资源检索/管理后台）。
- 分面计数随查询和筛选变化重算，由检索目录返回。
- 图谱组件需支持「全库轻量模式」与「局部 ego 模式」两种数据装配。

## 明确不做

- 不做 AI 回答缓存（原型期）。
- 不做图谱内搜索定位以外的复杂分析（最短路径、聚类等）。
- 素材不做独立图谱节点。
