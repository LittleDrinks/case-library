# ADR 0015：案例是内容边界
案例由一份正文、案例附件、批注和版本组成。网页采集与上传文件先成为案例附件，案例发布前全部附件随工作版本归作者私有。
事实依据指向本案例附件的原文片段；引用案例指向另一个案例的不可变已发布版本。提交版本冻结正文、全部附件和被引用案例版本，不再区分“已使用”或“随附”附件。
案例发布后，版本包中的全部附件投影为素材并进入素材库。公开案例同时公开每个素材的名称；公开、校内、私密三级只控制摘要、原文、来源链接和文件内容，私密内容仅来源案例作者与管理员可读。
素材记录始终指回来源案例版本与附件，没有独立创建流程。相同规范化 URL 或内容指纹只形成一条素材，多个来源附件通过挂载关系共同指向它；新挂载不覆盖聚合素材已有访问级别，来源案例下线时仅移除对应挂载。
