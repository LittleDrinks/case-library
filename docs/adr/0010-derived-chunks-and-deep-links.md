# ADR 0010：派生切片与层级深链（文件 = 数据源，切片 = 派生物）

状态：已定案（2026-07-22 grilling 会议）；当日实现

## 背景

- ADR 0009 让素材挂上真实文件后，同一本教材存在两种形态：结构化知识节（kn-xx，52 节）与原始文件预览。用户提出「删碎片」方案，grilling 后确认：碎片不能删（检索语料、12 条既有引用、图谱骨架都依赖它），但必须**降级为派生物**——文件是唯一数据源，切片由规则自动派生。
- 第一版扁平 `s-N` 序号被否决：它把章/节压成一层，丢失知识坐标层级。教材本身是三级结构（`#` 章 7 / `##` 节 15 / `###` 目 52),kn 条目（如 kn-01-02）本身就是层级坐标。

## 决策

### 1. 切块规则（唯一一份，前后端各一份实现，测试对齐）

- 按 `#{1,3}` 标题行把文件切成标题树；标题前的正文为「文首」块。
- 地址 = **结构路径**：文件中出现的标题级别按 # 数排序为第 1..K 层，路径 = 各级序号拼接（缺层不占位）。教材 `2.1.1`（章.节.目）、学习资料 `1.4`（栏目.篇）。
- 不合并、不二次切分；无标题文件 = 单块（退化为整文预览）。
- 前端 `U.chunkMd()`（运行时从文件文本派生）与 `tools/build_data.py assign_file_secs()`（构建期给 kn 节算 `fileSec`）严格同规则；一致性以「52 个 kn 节的 fileSec 路径指向的切片标题与 kn 标题逐一相同」为验收（已实测 52/52)。

### 2. 深链路由

- `#/material/<id>?sec=<路径>` 直达切片，可分享；分页器与目录树点击用 `history.replaceState` 更新地址（不触发整页重渲染）。
- 知识详情页「打开教材此节」→ 跳到教材素材的对应切片：kn-01-02 ↔ 教材文件切片 `1.2`,**知识坐标与文件坐标同构**。

### 3. 预览形态

- 单块文件：整文渲染（原行为）。多块文件：左侧目录树（按层级缩进、当前节高亮）+ 右侧切片正文 + 上一节/下一节。
- 69 期学习资料、教材、上传的 md 文件全走同一规则，上传即获得切片与深链。

### 4. kn 碎片保留

检索语料、案例引用、图谱骨架、知识详情页全部不动。kn 条目新增 `fileSec` 字段作为与文件切片的对齐锚点。

## 后果

- 「目录」成为对一本书精准引用的界面：教材素材详情页呈现完整章节目录树，每节有稳定深链。
- 引用模型不变：案例仍引用 kn 节（知识坐标）或素材 id；文件切片深链提供同一内容的文件形态入口。

## 明确不做

- 学习资料全文不入检索语料（正式版切块入向量库的管线）。
- 案例引用不写到文件切片级（引用模型手术，正式栈再议）。
- Copilot 不接入切片内容（AI 回答主路径演示前不动）。
- 切块不做大小合并/二次切分（演示语料实测无退化；规则将来收紧时路径仍稳定，扁平 page=N 才会漂移——这正是选结构路径的原因）。
