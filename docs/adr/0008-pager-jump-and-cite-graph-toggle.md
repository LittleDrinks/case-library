# ADR 0008：分页跳转与详情页引用区列表/图谱切换

状态：已定案（2026-07-21 grilling 会议续）

## 背景

两个小改进点由用户直接提出：①检索页分页器只能逐页点，页多时不便；②案例详情页的「引用关系」静态 SVG 环（P.egoGraph）与「引用（N）」列表是两张分离的卡，且用户希望图谱是力导向图。

## 决策

1. **分页器加页码跳转**：页码序列后追加「跳至 [输入] / N 页 [跳转]」，回车或点按钮生效，越界自动收敛到 [1, N]。
2. **详情页引用区合并为单卡片**：「引用（N）」卡片头部加 列表/图谱 切换（复用 `.view-toggle` 样式，默认列表）。
   - 列表 = 原引用清单（保留 `#cite-card-N` 锚点，正文〔n〕互跳不受影响）。
   - 图谱 = 两跳力导向图（本案例 → 引用目标 → 同样引用该目标的其他案例，每目标二跳案例上限 6 个），复用 `Graph.render` 力导引擎；单击节点直达对应详情页。
3. **图谱组件通用化**：`Graph.render` 新增 `opts.data`（直接给定 {nodes, links}，跳过全库装配）与 `opts.noCache`（不读不写全局 posCache，避免局部图与全库图串位置）；两跳 ego 数据装配统一为 `Graph.egoData(caseId, citationsOverride)`，详情页与工作台共用。
4. **工作台资料页签同步改造**（同日跟进）：引用区合并为「本案例引用（N）」一节 + 列表/图谱切换，列表保留原有的定位/移除动作，图谱同第 2 条。原静态 SVG 环（`P.egoGraph`）随两处改造完成退役删除。

## 后果

- `graph.js` 的渲染引擎与数据装配解耦，后续任何局部图都可复用。
- 详情页与工作台离开页面/切换页签时 `Graph.stop()` 释放动画帧。
- 静态 SVG ego 环（`P.egoGraph`）及其 CSS 已删除。

## 明确不做

- 图谱视图不提供节点浮卡（区域太小，单击直接打开）。
- 工作台引用列表的定位/移除动作不进图谱视图（图谱只读导航）。
