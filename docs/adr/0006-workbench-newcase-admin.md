# ADR 0006：工作台、新建流程与管理后台

状态：已定案（2026-07-19 grilling 会议）

## 背景

工作台统一承接案例写作、资料使用与教学成果生成；管理员维护分类目录、模板、审核队列和发布内容。

## 决策

### 1. 工作台

- 页签收敛为三个：Copilot / 批注 / 资料。
  - 「任务」页签删除，任务进度与失败重试只在 Copilot 对话流中呈现。
  - 教学成果通过工作台 AI 生成，确认后保存到当前案例正文或资料区。
- 头部加「大纲」开关：浮动小节目录，点击定位，平时收起。
- 头部加保存状态字：「已保存 HH:MM / 保存中… / 保存失败可重试」。
- 资料页签顶部嵌局部引用关系图（ego 模式，见 ADR 0004）。

### 2. 新建案例页

- 教师可直接创建草稿，标签在案例属性区补充；管理员可将标签组设为投稿必填，创建时不阻断。
- 模板卡片只展示：模板名 + 小节结构预览（会生成哪些小节标题）。
- 删除「主题或教学要求」输入框（主题在 Copilot 对话中表达）。

### 3. 管理后台

案例审核 / 发布管理 / 素材管理 / 类型与模板 / 账号 / 公告管理。

- 素材与案例管理**改回后台表格**（不并入检索页）；各表格加搜索框，整体打磨细节。
- 案例审核队列：搜索 + 提交时间排序 + 按作者筛选；自检计数列；详情页补版本 diff 与历史审核记录（见 ADR 0001）。
- 素材管理：跟进生命周期（被引次数 / 最近被引 / 待淘汰列与筛选，见 ADR 0003）。
- 类型与模板：模板小节结构可编辑（不再写死）。
- 公告管理：公告的发布 / 下线，供首页动态卡展示（见 ADR 0002）。
- 知识内容由受控 Markdown 数据源构建，不在管理后台在线编辑。

### 4. 版本模型

提交冻结并审核快照，审核结论产生前可撤回；通过即发布。已发布案例可另开新稿，旧版保持公开，新版通过后更新默认展示。

## 后果

- 工作台组件需支持作者/审核双模式复用（ADR 0001）。
- 模板数据从代码常量迁移为可编辑数据（`db.templates` 覆盖层）。
- 公告需要 `db.announcements` 存储。

## 明确不做

- 检索页不做管理模式。
- 知识库在线管理不做。
