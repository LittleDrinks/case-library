# ADR 0002：首页定位与信息架构

状态：已定案（2026-07-19 grilling 会议）

## 背景

首页原为「统计卡 + 我的案例 + 最新公开案例 + 按课程推荐（实为新建入口）+ 最近素材」的公告栏混合体。「按我的课程推荐」名不副实（点击跳新建页）；统计卡是死数字；「我的案例」随年份增长无分组无分页。

## 决策

### 1. 信息架构（导航）

`首页（推荐） / 我的案例 / 资源检索 / 管理后台`（管理后台仅管理员可见）。

- 知识图谱从导航撤下，并入资源检索页（见 ADR 0004）。
- 「新建案例」入口放在「我的案例」页。

### 2. 首页 = 推荐

- 算法推荐：按当前用户学段 + 高赞/高引用/最新 混合推荐已发布案例与素材。无人工运营位。
- 动态卡（替代原「我的数据」统计卡，原统计卡删除）：
  - 平台增量动态：昨日/本周新增案例、素材、发布数，点击跳检索页按时间排序。
  - 时政新闻流：经 `/api/web-search` 抓思政/高教相关新闻 3-5 条；**本轮只展示 + 跳原文**，不入库。
  - 平台公告：管理员在后台「公告管理」发布/下线的通知。

### 3. 我的案例（独立页）

- 顶部待办区（退回待改 / 待处理批注，含空态）；有待办时导航「我的案例」显示红点/数字。
- 案例按状态分组：进行中（草稿+退回）/ 审核中 / 已发布，组内分页，不做「全部展开」。
- 「我的备课材料」区块：在案例详情页生成的教学设计/讨论题/PPT 提纲归生成者个人，存于此（见 ADR 0005/0006）。
- 不显示「我的数据」统计卡。

## 后果

- 首页从公告栏变为内容发现页；个人工作管理集中在「我的案例」。
- 需要 admin 公告的存取（`db.announcements`）。
- 新闻流抓取需要服务端定时或按需刷新；本轮为按页面加载时拉取 + 短期缓存。

## 明确不做

- 新闻流本轮不做入库/线索池/一键采集（见 ADR 0003 的后续项）。
- 不做全局通知铃铛。
- 统计卡不做可点击跳转（已删除而非改造）。
