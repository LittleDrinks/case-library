# ADR 0009：素材真实文件与演示鉴权（文件管理闭环）

状态：已定案（2026-07-22 grilling 会议）；当日实现，次日演示
修订：教材的「素材」身份已由 ADR 0011 收回（教材出素材库，转入知识层级），其余决策不变。

## 背景

- demo 上线后老师提出：虽然是 demo，仍须**完整展示文件管理功能**（重点）。
- 初期资料在 `assets/`：《自然辩证法概论（2025版）》.md + `学习资料md.rar`（69 期中心组学习资料 md，解压约 8MB）。
- 现状三个缺口：
  1. 素材只是元数据记录，`build_data.py` 仅保留最新 12 期、每期 1600 字副本，**没有真实文件**；
  2. 全部状态在浏览器 localStorage，`server.py` 无上传接口、无文件存储；
  3. 「登录」是页头用户切换下拉，所有权限判断（`canSeeMaterial` 等）仅在前端，服务端不认身份。
- 时间盒：**次日演示，老师亲自上手操作**，交互必须扛住乱点。

## 决策

### 1. 文件管理 = 给现有素材挂真实文件

不新建独立「资料库/网盘」实体。素材详情页增加文件区：在线预览（md 渲染）+ 下载。这是老师需求的定界。

### 2. RAR 拆包，每期一条素材

- 69 期学习资料各自成为一条素材 + 教材 1 条，共 **70 条种子素材**，每条挂完整 md 文件；RAR 本身不上传。
- `tools/build_data.py` 扩展：抽取全部 69 期完整文件落盘并登记索引（数据源由 `docs/` 改为 `assets/`）。

### 3. 真上传，服务端落盘，所有人可见

- `server.py` 新增文件接口（上传/列表/下载/删除/密级调整 PATCH），文件落盘 `files/`，上传素材的记录存服务端 `files/index.json`。
- 客户端加载时把服务端上传素材并入 `db.materials`（沿用 `customMaterials` 合并模式）。
- 上传限 20MB，base64 JSON 传输（stdlib 无 multipart 解析，不做过度工程）。

### 4. 演示鉴权：token + 三级内容权限

- 页头选账号 = 登录；服务端签发 HMAC token（`APP_SECRET` 存 `.env`，有效期 12h），无密码。
- 上传入口在管理后台素材管理页，仅 admin（与 ADR 0003「采集不是普通用户随意动作」一致）；删除仅 admin。
- 读操作服务端强制：level 0 公开内容人人可读，level 1 校内内容仅登录用户可读，level 2 私密内容仅来源案例作者和管理员可读。已发布案例的素材名称不受内容权限影响。
- 管理后台调整素材密级时同步 PATCH 到服务端索引，保证「界面显示」与「下载强制」一致；种子条目的密级在重新运行 `build_data.py` 后回到默认值。

### 5. 种子素材只能停用不能删

老师亲自操作，防止误删种子导致演示事故。上传素材 admin 可删（服务端删文件 + 索引）。停用维持现有前端逻辑。

### 6. demo 现有功能不裁剪

演示前一天砍功能只增回归风险、不给老师加分。「功能是否太多」是正式栈重建时的范围问题，不是现在的问题。

### 7. 演示后切正式技术栈

正式仓库 v1（功能跑偏、bug 多）**不在其上修补**；重建以本 demo 已定案的 IA/ADR 为准。正式栈范围另开 grilling、另行 ADR。

## 后果

- demo 由纯静态变为「静态 + 轻状态」（`files/` + `index.json`）；部署需保证 `files/` 可写且不提交 git。
- `.env` 增加 `APP_SECRET`。
- 上传素材的文件与记录权威在服务端；其 `citedCount/lastCitedAt` 等使用度数据仍走 localStorage（已知限制，演示可接受）。
- 素材详情页、管理后台素材管理页、页头用户切换（登录态）均有改动。

## 明确不做

- 不做密码登录 / 完整账号体系（正式栈再议）。
- 不做 multipart、断点续传、病毒扫描、文件多版本。
- 不砍 demo 现有功能。
- 不做新闻线索池与自动入库（ADR 0003 已记录）。
- 不在 v1 正式仓库上修补。
