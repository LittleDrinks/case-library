# ADR 0011：知识与素材分层（教材出素材库 + 知识管理入口）

状态：已定案（2026-07-22）；当日实现

## 背景

ADR 0009 为了让教材挂上真实文件，把教材登记为一条素材（m-book-zrdb）。这是实现捷径，但造成领域混层：教材出现在素材管理与素材检索里，而「知识」（教材结构化章节）没有任何管理入口。

## 决策

### 1. 分层定义

- **素材**：教学参考文件与链接（学习资料、政策文件、教师上传）——可上传、可删除/停用、按密级管理。
- **知识**：教材的结构化章节（章→节，构建期从教材文件派生导入）——不经素材管道，不可逐条删除。

### 2. 教材出素材库

- 素材回到 77 条（8 登记 + 69 期），教材不再出现在素材管理与素材检索。
- 教材文件信息独立为 `data.js` 的 `bookFile`（不入 `db.materials`）;files 索引锚点由 `m-book-zrdb` 改为知识来源 `ks-zr`。
- 旧路由 `#/material/m-book-zrdb` 退役（404)。检索内容无损：教材文本本就以 kn 节存在于语料。

### 3. 教材主页 `#/book`（知识层级入口）

- 教材信息卡（来源/版本/更新/结构）+ 章节目录（每章引言 + 节标签链到知识详情）+ 原始文件切片（与素材详情页共用 `P.fileSliceCard` 组件）。
- `#/book?sec=<结构路径>` 深链；知识详情页「教材」「原始文件」两行均链入。

### 4. 管理后台「知识管理」页签

- 知识来源登记台账（8 个来源：名称/版本/更新/条目数/状态），ks-zr 显示实时的已导入节数。
- 教材文件卡：查看教材主页、下载文件；更换教材的路径（替换 assets → 重跑 build_data.py）写明在页面上。

## 后果

- 领域模型干净：素材管理与知识管理并列为两个页签，教师看到的教材在知识侧（检索知识 tab、教材主页），不再混入素材。
- `P.fileSliceCard` 成为文件预览的唯一实现（素材详情、教材主页共用）。
- 检索页目录态（空查询浏览）下，知识按「资源实体」聚合为教材 1 条（计数口径：全部 85 / 案例 7 / 知识 1 / 素材 77)，碎片进 `#/book` 浏览；检索态仍按节命中（ADR 0007 混合结果流不变）。

## 明确不做

- 新知识来源的在线导入流程、教材在线替换、知识内容编辑——均属正式栈管线。
- 学习资料等素材不建「素材主页」，素材详情页已足够。
