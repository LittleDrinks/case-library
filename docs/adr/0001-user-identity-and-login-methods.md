# 用户身份与登录方式分开

平台保留稳定的内部用户 ID，案例作者、私人对话归属和访问权限继续关联这个 ID；本地密码和上海大学 SSO 是可绑定到同一用户的登录方式。先交付本地密码版用户管理，学校 SSO 不作为上线前置条件，待正式接入协议、字段及验证规则明确后再接入。

这样，增加或更换登录方式时，可以保留既有稿件、投稿、引用和权限。姓名、学／工号作为资料或外部身份属性保存，不能单凭用户自填的这些资料自动合并账号；学校认证验证成功后绑定原账号。学校返回属性与用户自填资料保留来源区别，平台角色和账号停用由本地管理。管理员停用账号或撤销校内素材权限的决定优先于后续登录的自动开通行为。

当前公开资料不足以确认学校将向本应用返回哪些用户属性；官方新生说明涉及激活新学号，也没有给出学工号作为永久人员主键的保证。调查及证据见[上海大学 SSO 返回属性调查](../research/shu-sso-returned-attributes-20260930.md)。
