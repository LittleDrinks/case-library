# 思政教学案例智能平台 · 用户手册

适用版本：当前 `app/` 前端 + `server.py` 服务端（v5）。
启动方式：项目根目录执行 `python3 server.py`，浏览器访问 `http://127.0.0.1:8080/`。
本轮设计决策记录见 `docs/adr/`（0001–0006 与术语表）。

## 2. 首页（推荐 + 动态卡）

设计：内容发现页。回答"有什么值得用的"，不是工作台。

- **平台动态**：近 7 天新案例 / 新素材 / 新发布数，全库总量；点「检索全部」进入资源检索。
- **时政要闻**：经联网检索抓取的思政/高教相关新闻，点击标题跳原文网站。**本期只做只读跳转**，不入库、不采集（素材线索池与自动入库是后续规划，见 ADR 0003）。会话内缓存 30 分钟。
- **平台公告**：管理员在后台「公告管理」发布的通知。
- **推荐案例 / 推荐素材**：算法推荐——按当前账号学段 + 点赞/引用/时间加权排序，无需运营。

## 3. 我的案例

设计：个人工作管理页，回答"我该做什么"。

- **待办**（常驻卡片）：退回待改的案例（显示待处理审核批注数，点「去修改」）、有待处理批注的草稿；管理员额外看到待审队列（点「去审核」）。
- **案例分组**：进行中（草稿+退回）/ 审核中 / 已发布，各组独立分页（每页 5 条），不做全部展开。
- **我的备课材料**：在案例详情页生成的教学设计/讨论题/PPT 提纲，归生成者个人。可查看（弹窗）、删除；点击案例名回到来源案例。
- 右上角**新建案例**。

---

## 4. 新建案例

设计：一页式三步——课程与学段 → 案例类型 → 模板就地展开。

- **课程与学段**：硕博公共思政 / 本科思政 / 专业课程思政（默认取偏好）。
- **案例类型**：两列紧凑卡片，显示名称 + 模板数与用途集合；点击选中。
- **模板列表**：选中类型后就地展开，每张卡片显示模板名、用途标签与**小节结构预览**（会生成哪些小节标题）。按学段过滤，无适配时显示全部。
- **创建并进入工作台**：按模板章节生成空白案例。模板不是硬性约束——正文是自由文档，小节标题可改可删。

## 5. 案例工作台（作者模式）

设计：左文档、右工具。左侧是一页 Word 式自由文档；右侧三个页签（Copilot / 批注 / 资料），随页面滚动保持在视口内。

### 5.1 顶部操作行

状态标签 + 操作按钮。**版本模型**：保存=在工作版本内保存；提交=冻结并生成新版本号；提交后内容不可再改；管理员「开始审核」前可撤回，撤回后基于最后一版继续编辑。

| 状态 | 可用操作 |
| --- | --- |
| 草稿 | 提交审核、历史版本、导出、删除、大纲 |
| 待审（已冻结） | 撤回提交、历史版本、导出、大纲 |
| 审核中（已冻结） | 历史版本、导出、大纲 |
| 已发布 | 查看公开页、历史版本、导出、大纲 |

- **完整度徽标**（草稿态）：实时显示自检通过数（共 6 项：标题、段落数、空标题、引用、字数、风险批注）。**自检未过项会自动生成「系统自检」批注**，修复后自动标记解决；点徽标可查看清单并跳到批注页签。全部通过时点提交直接成功，有未过项时可「仍要提交」。
- **保存状态**：编辑时显示「保存中…」，自动保存后显示「已保存 HH:MM」。
- **大纲**：浮动小节目录，点击定位，写长案例时导航用。

### 5.2 正文（自由文档）

- 像 Word 一样直接录入、删改；**标题只是带格式的文字**，工具条「B / 标题 / 正文」切换格式，粘贴自动转纯文本。
- 光标所在段落有底纹标识，Copilot 默认针对光标所在逻辑小节（面板底部显示"当前位置"）。
- **选中一段文字 → 浮出「+ 批注」按钮**：给自己或给审核员留下锚定到原文的批注（选区原文 + 所在小节）。
- 文末**参考文献区**：自动列出全部引用，编号〔n〕按正文出现顺序自动重排；不可手编，随引用增删更新；与右侧资料页签的引用条目可双向跳转定位。

### 5.3 Copilot 页签

能力（工具）范围：知识库检索（《自然辩证法概论（2025版）》52 节）、素材库检索（按权限过滤）、联网检索、网页采集（含查重）、写入正文（须确认）、审校并生成批注。

- **快捷指令**：查找理论依据 / 查找权威素材 / 检查引用与错别字 / 润色当前节 / 学段改写。点击把提示词插入输入框，可改后再发。
- **粘贴素材 ID**（m-xxx / kn-xxx，来自素材详情页「复制引用 ID」）直接发送 → 自动挂接引用并在当前位置插入标注。
- **粘贴链接** → 采集为素材。**查重双闸**：URL 已采集过直接提示复用；检出相似素材时列出 top-3 并询问「仍要采集」。
- 结果采用：替换/追加当前小节、存为新节；审校结果一键「加入批注」。任务进度与失败重试都在对话流中。

### 5.4 批注页签

批注是平台所有反馈的统一载体，五种来源：**AI 建议 / 审核员 / 风险提示 / 系统自检 / 我的批注**。

- 状态筛选（待处理/已采纳/已拒绝/已解决/已失效）+ 来源筛选；点击引用原文定位到正文。
- 作者操作：AI 建议可采纳/拒绝，任何批注可**标记解决**；每条批注下方有**回复框**，可写一句处理说明。
- **批注线程**：作者的回应、审核员的追问都在同一条批注下追加；审核员对已解决的批注可「追问并重开」。
- 失效批注可「请 Copilot 重新判断」模糊重挂；「批量采纳低风险」一键处理文字/格式类建议。

### 5.5 资料页签

- **引用关系图**（ego 图）：本案例引用了哪些教材节/素材的放射图，节点点击进详情，红色 +N 表示另有 N 个案例引用同一资源。
- **本案例引用**：每条支持 定位（跳到正文标注处）/ 查看 / 移除。
- **采集网页为素材**、**联网检索公开资源**（白名单域名自动判权威；URL 查重）。
- **相关知识 / 相关素材**：点「引用」即在当前位置插入〔n〕并挂接。

### 5.6 导出与历史版本

- 导出：校内完整版 / 对外申报版（自动剔除校内与受限引用，需确认脱敏）；可选正文/教学设计/讨论题/PPT 提纲/参考文献；未定稿带草稿标识；页脚含平台名、时间、状态与版本类型。
- 历史版本：新建/提交/退回/发布各节点自动留档，可查看快照。

## 6. 资源检索（列表 / 图谱 双视图）

设计：案例、知识、素材的统一入口。

- **搜索框**：自然语言或关键词。本地分词 → 停用词过滤 → LLM 查询理解扩展（页面显示"已扩展检索"）→ BM25 排序 + 权威/时间加权。
- **AI 回答**（省流模式）：只在两类情况自动生成——本地结果不足（<3 条）或问题式查询（含"哪些/怎么/为什么/如何"或为长句）；其余显示"命中明确，未生成 AI 解读"，可点「生成 AI 解读」手动获取。回答可折叠，折叠状态跨检索记忆。
- **分面栏**：计数=当前查询+其他筛选下的结果集（选中实时收窄）；只显示与当前页签相关的组（知识页签不显示案例/素材维度）。
- **排序**：按页签变化——案例：综合/最新/点赞；素材：综合/最新/被引优先；知识：综合/教材顺序。
- **结果**：全部/案例/知识/素材页签（带数量），全部下分组预览，具体页签每页 10 条。
- **图谱视图**：检索框旁「列表 / 图谱」切换。默认只画教材骨架（章/节）+ 案例节点；检索词命中的节点红圈高亮。**单击节点出浮卡**（标题/类型/摘要/打开；案例可「展开素材引用」——素材不单独成点，点开案例才展开其引用）；**双击节点直达详情**；空白双击复位视图。

## 7. 案例详情页（公开页）

设计：只读发布快照 + 读者工作台。

- **左侧目录**：小节目录，点击定位，滚动时高亮当前节。
- **正文**：发布快照内容，〔n〕引用上标可点击，跳到右侧引用清单；文末参考文献区。
- **引用关系图**（右栏）：本案例引用网络放射图。
- **操作**：点赞、收藏、复制链接、导出 Word；作者/管理员可打开工作台。
- **结合案例备课**（已发布案例）：任何登录用户可生成教学设计/讨论题/PPT 提纲（真实 AI），生成物保存到「我的案例 → 我的备课材料」，归生成者个人，不随原案例公开。
- **相关案例**：同类型 + 同学段 + 共享引用加权推荐。
- 引用的受限素材对未授权读者不可见。

## 8. 素材详情页

设计：一份素材的全部事实 + 使用度。

- 元信息：来源、原始链接、发布/采集时间、可信度、密级、适用范围、状态。
- **使用度**：被 N 个案例引用 + 最近被引时间。「被引用」是素材"被用"的唯一口径（浏览不计）。
- **可信度分级**：权威来源（白名单/官方，可直接引用）/ 一般来源（已登记，需注明出处）/ 待核实（非白名单，引用前需核验），各档有视觉区分与说明。
- **时效提示**：文档类（政策文件）发布超过 3 年显示黄色提示条；有原始链接的可**重新采集**更新内容副本。
- **复制引用 ID**：复制素材 ID（m-xxx），粘贴到工作台 Copilot 即把该素材加入当前案例引用。
- **待淘汰标**：入库超 30 天且从未被引用的素材自动标记。
- 引用该素材的案例（反向追溯）；管理员可直接改密级/可信度/状态/标签。

## 10. 管理后台（仅管理员）

六个页签：

- **案例审核**：待审队列支持**搜索**（标题/作者）、**按作者筛选**、**提交时间排序**；每行显示提交轮次与作者自检完整度。点「审核」进入审核工作台。
- **发布管理**：已发布/已隐藏案例的隐藏与恢复（支持搜索）；风险处理——状态异常素材及其受影响案例，可「要求复核」（自动向作者发审核批注）。
- **素材管理**：密级/可信度/状态维护；**被引次数**列与「只看待淘汰」筛选，待淘汰素材可一键「淘汰」（置为停用，检索与详情不再展示）；权威来源白名单增删。
- **类型与模板**：类型增删；模板可**编辑**（名称/用途/适用学段/章节结构）、新增、删除。
- **账号权限**：素材范围上限调整；重置全部数据。
- **公告管理**：发布/下线公告，展示在首页「平台公告」卡。

### 审核工作台（= 工作台只读模式）

审核员看到的是与作者完全相同的工作台界面（同文档、同批注面板、同 Copilot），区别：文档只读 + 右侧多出「审核动作」卡。

- **批注即意见**：退回修改/要求补充前必须至少挂一条批注（选中正文文字添加，或采纳 Copilot 审校产出的候选批注）；否则动作被拦截。「总评」可选。
- **审核动作**：开始审核（冻结待审版本，作者不可再撤回）→ 通过并发布 / 退回修改 / 要求补充 / 暂时隐藏。
- **Copilot（审核场景）**：AI 辅助审校（产出候选批注列表，勾选挂载）、核查理论依据、核查权威素材。
- **版本对比**：第 2 轮起的提交，可切换「与上一版对比」，文字级增删高亮。
- **历史审核记录**：前几轮结论、总评、轮次。
- **批注线程**：审核员可回复批注、对已解决的批注「追问并重开」；作者的处理回应跨轮保留。

## 11. 数据与配置说明

- **数据持久化**：演示改动（案例、批注、审核、模板、公告、备课材料、收藏）保存在当前浏览器 localStorage，换浏览器不共享；管理后台可一键重置。
- **素材内容**：教材全文、4 篇示例案例、69 期中心组学习资料由 `tools/build_data.py` 生成 `app/data.js`。
- **AI 配置**（`.env`，密钥只在服务端）：`AI_BASE_URL` / `AI_API_KEY` / `AI_DEFAULT_MODEL`；`AI_MODELS` 模型白名单；`AI_REVIEW_ENABLED` 控制审核相关 AI 能力；`TAVILY_API_KEY` 开启联网检索与首页时政要闻。
- **ANYSEARCH_API_KEY**：`.env` 中存在但未接入（本机无对应服务端点）；联网检索统一走 Tavily 通道。
- **导出**：Word 文件由服务端 `python-docx` 生成，页脚注入时间、状态与版本类型。
