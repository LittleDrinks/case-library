# Garden observation notes

**Fictional source:** Northbank Learning Studio<br>
**Publication:** Small Garden Water, edition 1 (2025)<br>
**Section:** Field record / paragraph 3

## Before the walk

Choose one planting bed and one nearby path edge. Visit both after the same light shower, and use the same short observation interval.

## Record what is visible

1. Note the time and location.
2. Describe changes in soil color and the shape of any shallow channel.
3. Mark direct observations separately from possible explanations.

The sample image in this package is a generated illustration for this demonstration. It does not document a real garden.

> “The path edge is darker than the bed after the shower.”
