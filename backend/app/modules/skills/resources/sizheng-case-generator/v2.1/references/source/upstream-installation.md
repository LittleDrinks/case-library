# 思政案例生成技能包（v2.1）安装与使用说明

一、这是什么

本技能包用于《习近平文化思想》课程（本科生通识课，兼顾研究生思政课）的思政案例写作。给定选题后，可按七步工作流生成案例文本（本科生版/研究生版）与配套教学设计，并附素材汇编与真实性验证记录。

核心特性：
1. 案例三级分级体系（国家案例、上海市案例、上海大学案例），动笔前先定级；
2. 上海大学案例实事求是铁律，只写可核实事实，不拔高阐释；
3. 理论锚点对接表先行，总书记言论逐字核对原文；
4. 本研双版本并行，核心事实一致、深度差异化；
5. 关键数据双来源交叉验证，存疑事项如实注明。

二、安装方法（WorkBuddy 用户）

1. 解压本压缩包，得到 sizheng-case-generator 文件夹；
2. 将整个文件夹复制到 C:\Users\<你的用户名>\.workbuddy\skills\ 目录下；
3. 重启 WorkBuddy 或新建会话，技能即自动生效；
4. 在对话中说"帮我写一个思政案例，选题是……"，技能会自动触发。

三、目录结构

sizheng-case-generator/
  SKILL.md                     技能主文件（工作流、结构、自检清单）
  安装说明.txt                 本文件
  references/
    模板规范_v2.0.md            模板规范（文件名保留v2.0，内容已更新至v2.1，含三级分级体系）
    examples/                  13个范例文件（4个案例的文本与教学设计）

四、范例说明

references/examples/ 下的范例均来自实际教学写作：
1. 228街坊（研究生版，结构最全的范本）
2. 崇明东滩（本科生版，参考模板源文件）
3. 红色娘子军（本研双版本，文艺领域选题，国本/校本对照）
4. 文化新空间（本研双版本+素材汇编，上海大学案例"上大力量"写法示范）

五、使用建议

1. 提供选题时，同时说明受众层次（本科/研究生/双版本）与希望对接的理论要点；
2. 涉及本校教师的案例，请提供可核实的事实材料（官方报道、学校官网等），技能将严格按实事求是原则处理；
3. 生成文档为 docx 格式，修改内容以红色标出，便于审阅。
