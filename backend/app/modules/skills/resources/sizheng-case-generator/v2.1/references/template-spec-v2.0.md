# 思政案例模板规范

---

## 一、选题原则

### 1.1 选题维度
- **紧扣习近平文化思想**：案例必须对应习近平文化思想中的关键性言论、观点，不预先指定具体教材章节；写作时需先明确该案例可对接哪些习近平文化思想核心命题（如"人与自然和谐共生""以人民为中心""系统观念""高质量发展""文化自信"等），再自然融入叙事
- **典型性**：选取具有全国或区域示范意义的实践样本，最好形成"可复制、可推广"的经验
- **时代性**：案例应反映新时代（党的十八大以来）的重大实践，体现党的创新理论的指导作用
- **贴近性**：案例需与学生生活、专业背景有内在关联，避免过于遥远或抽象
- **可检索性**：选题必须有足够丰富的公开素材可供联网检索（政策文件、新闻报道、学术研究、统计数据），这是素材真实性的前提

### 1.2 选题结构
采用"**主标题——副标题**"形式：
- 主标题：点明理论视角或核心价值（如"生态保护优先""高水平社会主义市场经济体制下的城市更新实践"）
- 副标题：明确案例地点与具体事件（如"——以杨浦区228街坊为例""——上海崇明东滩湿地生态修复与生物多样性保护，打造长江口生态屏障"）

### 1.3 习近平文化思想关键言论匹配指南
在撰写前，需先完成"理论锚点对接表"，列出案例将引用的习近平文化思想核心表述（精确到原话，注明出处）：

| 思想维度 | 典型关键言论（示例） | 适用案例类型 |
|----------|---------------------|------------|
| 生态文明 | "人与自然是生命共同体""绿水青山就是金山银山""像保护眼睛一样保护生态环境" | 生态治理、环境保护类 |
| 人民城市 | "人民城市人民建，人民城市为人民" | 城市更新、基层治理类 |
| 系统观念 | "山水林田湖草沙是生命共同体""统筹发展和安全" | 系统治理、综合施策类 |
| 高质量发展 | "新发展理念""高质量发展的内在要求" | 经济转型、产业升级类 |
| 文化自信 | "两个结合""中华民族现代文明" | 文化传承、遗产保护类 |

**注意事项**：
- 关键言论必须引用原文，不可自行改写或概括替代
- 引言位置应自然嵌入叙事或分析段落，不宜孤立堆砌
- 每个案例至少对接3-5条关键言论

### 1.4 案例分级体系

所有案例分为三级，动笔前必须先定级。课程以汪老师为上海大学教师的身份为前提设计：

| 级别 | 对象 | 叙事重心 | 在课程中的地位 |
|------|------|---------|--------------|
| 国家案例 | 全国性实践（总书记重要论述的发生地与考察点、国家战略工程、全国性文化工程） | 理论高度与普遍意义 | **课程主体，最重要** |
| 上海市案例 | 上海贯彻落实习近平文化思想的实践（最佳实践地建设、城市文化治理、重大文化工程） | 治理逻辑与经验提炼 | **课程主体，最重要** |
| 上海大学案例 | 上海大学师生参与文化建设、理论传播的实践 | 上大人的参与感 | 服务教学，目的是激发学生对学校的认同感 |

**分级写作要求**：

1. 国家案例与上海市案例应占多数；上海大学案例宜精不宜滥。
2. 案例可跨级（如上海市实践对接国家论述、上大师生参与上海市实践），须明确主归类，并如实区分各层级角色。上海大学案例可以上海市实践为主体内容，但上大维度须有独立落点（如"举措与实践"下设"上大力量"小节，或举措分条中专列一条），本研双版本的上大表述事实一致。
3. **上海大学案例的铁律是实事求是、不拔高**：
   - 只写可核实的事实，即谁、以什么身份、做了什么、出品方或报道来源是什么；
   - 重点呈现上大人在传播、发扬、践行习近平文化思想方面所做的努力；
   - 严禁"深度参与顶层设计""全面参与""引领"等无出处的拔高表述，学理分量靠被写者的学术身份与实际作为支撑，不靠形容词；
   - 涉及教师身份（职称、人才计划、学术兼职）须以学校官网等权威来源核实后写入，并在素材汇编中记录来源；
   - 参与事实的叙述宜采用"应邀""出镜解读""以学者身份参与"等与事实相称的动词，慎用"主导""担纲""投身"等超出事实的动词。

## 二、写作角度与本研双版本设计

### 2.1 角度定位
- **研究生案例**：侧重制度逻辑、治理机制、理论纵深，呈现多维矛盾与深层张力，理论密度高
- **本科生案例**：侧重理念阐释、实践过程、价值引领，叙事直观，难度梯度较低，理论融入叙事

### 2.2 本研双版本差异对照表

| 维度 | 研究生版本 | 本科生版本 |
|------|-----------|-----------|
| 摘要 | 200-300字，含理论框架与研究视角 | 150-250字，概述背景、举措、成效 |
| 背景 | 深入历史沿革+制度语境，铺垫理论问题 | 简明交代时空坐标+问题缘起 |
| 困难 | 呈现矛盾的多维性（政治/经济/社会/文化交织），剖析制度性根源 | 突出实践层面的两难选择，呈现问题意识 |
| 举措 | 从制度创新、机制设计层面展开，揭示政策逻辑 | 从操作层面展开，说明"做了什么、怎么做到的" |
| 成效 | 强调理论贡献、制度意义、学术价值 | 强调实践效果、社会反响、可感性成果 |
| 总结 | 回归理论体系，构建"理论—实践—理论"闭环 | 提炼思想启示，强化价值认同 |
| 教学设计 | 学情分析侧重理论思辨能力，讨论题偏重辨析与论证 | 学情分析侧重认知特点与情感共鸣，讨论题偏重理解与践行 |

### 2.3 理论对接点设计
每个案例需预设2-4个明确的理论对接点，直接对应习近平文化思想的关键言论，而非具体教材章节。

## 三、案例文本结构（六模块）

```
一、摘要和关键词
二、案例背景
三、遇到的困难（或时代背景/问题意识）
四、举措与实践（核心正文）
五、成效与推广
六、案例总结 + 附录
```

### 3.1 摘要和关键词
- **摘要**：150-250字，概述案例背景、核心问题、主要举措、取得成效，以及案例与理论的对接口径
- **关键词**：3-5个，含主题词、理论词、地域/对象词

### 3.2 案例背景
- 交代案例对象的时空坐标（地点、时间、历史沿革）
- 说明案例的典型意义（为什么选这个案例）
- 铺垫时代背景：国家政策、地方实践、历史条件等
- **写作技巧**：先纵向历史回溯（过去怎样），再横向现实呈现（问题是什么）

### 3.3 遇到的困难（矛盾张力的呈现）
- 用"第一、第二……"或编号列出具体困难/矛盾（228案例为五大矛盾）
- 每个困难需包含：问题实质、两难性质、影响范围
- **关键**：困难描述要具体到数据、比例、数字（如"72%房屋砖木结构""360户居民征收"）

### 3.4 举措与实践（核心部分）
- 先写理念转变（从什么到什么），再写具体措施
- 措施分条阐述，每条以"第一、第二……"或"一是、二是……"引导
- 每条措施需包含：做什么、怎么做、为什么这样做（体现理论逻辑）
- **要求**：措施与背景中的困难一一对应，形成"问题—对策"闭环

### 3.5 成效与推广
- 按维度分项呈现成效（如空间价值、经济活力、社会功能、示范影响）
- 每维度需有**量化数据**支撑（百分比、金额、人次、覆盖率等）
- 注明获奖情况、入选名录、国际认可等外部认证
- 提炼可推广的经验（名称化，如"东滩模式""151030机制"）

### 3.6 案例总结
- 首段：总括性理论定位（回归教材理论框架）
- 分点阐述：每个理论对接点展开，先引理论原文，再结合案例细节分析
- 结尾：升华价值，呼应开头的时代背景，指向普遍意义

### 3.7 附录
- 教材依据（1-2部）
- 政策文件（中央或地方）
- 学术文献/新闻报道（2-4篇）
- 格式：按学术规范标注作者、书名/刊名、出版社/期刊、年份、版次

## 四、教学设计结构

```
一、教学说明
二、教学文本内容
    （一）导语
    （二）教学内容描述
    （三）教学内容分析（教学要点+教学过程+教学方法）
    （四）思考讨论题
三、附件（参考文献）
```

### 4.1 教学说明
- **教学目的**：含知识目标、能力目标、价值目标三个维度
- **阅读思考题**：3-4道，覆盖案例理解、理论对接、价值反思
- **教学安排**：课时分配建议（通常90分钟，2课时）

### 4.2 教学内容描述
- **导语**：用1-2段介绍案例背景，引出主题，营造情境
- **教学内容描述**：对应案例文本的核心内容，供教师授课参考

### 4.3 教学内容分析
- **教学要点**：2-4个，每个要点含理论阐释+案例解读+价值引领三层
- **教学过程**：四段式结构——情境导入（10min）→案例剖析（20min）→理论解读（15min）→研讨升华（分组讨论+汇报+总结）
- **教学方法**：案例教学法、问题导向法、小组研讨法等

### 4.4 思考讨论题
- 与阅读思考题呼应，课堂深化用
- 题型：理解类、分析类、反思类、践行类

## 五、行文风格规范

### 5.1 语言特征
- **学术性**：使用规范的学术表达，避免口语化
- **政理性**：准确引用政治术语、理论表述（需与教材原文一致）
- **叙事性**：案例背景和实施过程用叙述性语言，增强可读性
- **数据性**：关键位置必须嵌入具体数据，增强说服力

### 5.2 句式特点
- 多用复句，少用简单句
- 常用"既……又……""不仅……更……"等关联结构呈现辩证关系
- 理论阐释段落多用"如……""以……为例"引出具体实例

### 5.3 修辞技巧
- **对比手法**：新旧对比（如更新前后）、正反对比（两种选择）
- **比喻手法**："候鸟天堂""天然净化器""红绿灯"等形象化表达
- **引语嵌入**：适时嵌入习近平总书记原话、政策文件原文

## 六、语体风格

| 维度 | 特征 |
|------|------|
| 整体基调 | 严肃而不失生动，理论性强但不枯燥 |
| 价值导向 | 坚定正面，体现制度自信、道路自信 |
| 叙事视角 | 客观陈述为主，适度体现立场判断 |
| 情感色彩 | 克制但有温度，通过数据和细节传递价值 |
| 理论密度 | 研究生案例：高（每段有理论锚点）；本科生案例：适中（理论融入叙事） |

## 七、格式规范

### 7.1 标题层级
- 一级标题：一、二、三、四、五、六（对应六大模块）
- 二级标题：（一）（二）（三）；1. 2. 3.
- 三级标题：第一、第二、第三；一是、二是、三是
- 四级内容：（1）（2）（3）

### 7.2 段落规范
- 每段控制在3-8行（约150-400字）
- 首行缩进两字符
- 理论阐释段落可适当加长，叙事段落宜短

### 7.3 数据呈现
- 数据精确到个位或小数点后一位
- 百分比用"%""百分之"均可，全文统一
- 年代用"2024年"而非"24年"

### 7.4 文献格式
- 教材：《书名》，出版社年份年版
- 政策文件：发文机关，《文件名称》，年份
- 期刊论文：作者，《篇名》，《期刊名》年份期数
- 网络资源：作者/机构，《篇名》，来源，URL（必要时）

## 八、反思检验与修改环节

### 8.1 真实性验证（素材核验）
在撰写前，必须对所有关键事实进行交叉验证：

| 验证维度 | 方法 | 标准 |
|----------|------|------|
| 数据准确性 | 至少两个独立来源交叉印证（官方数据+学术研究或新闻报道） | 数据差异需标注说明，避免明显矛盾 |
| 事件时间线 | 对照政策文件发布时间、新闻公告日期、实施时间节点 | 年代、数字精确无误 |
| 引用原文 | 习近平文化思想关键言论须与《习近平谈治国理政》等权威出版物一致 | 不得改写、缩略、意译替代原文 |
| 政策文件 | 核对发文机关、文号、年份是否准确 | 以政府官网为准 |

**数据来源优先级**：政府官方网站 > 权威媒体（人民日报、新华社） > 学术期刊 > 一般新闻报道

### 8.2 模板符合性自检
完成初稿后，逐项对照以下检查清单：

- [ ] 案例级别已明确（国家/上海市/上海大学），跨级案例已注明主归类；上海大学案例的上大参与仅含可核实事实、无拔高表述，教师身份信息经权威来源核实
- [ ] 标题格式：主标题——副标题，含理论视角或核心价值
- [ ] 摘要包含：背景、核心问题、主要举措、成效、理论对接口径
- [ ] 关键词3-5个，含主题词、理论词、地域/对象词
- [ ] 背景段落包含历史沿革+时代背景+典型意义
- [ ] 困难/问题段落是否呈现矛盾张力（至少2个矛盾维度）
- [ ] 举措段落是否与困难段落一一对应，形成"问题—对策"闭环
- [ ] 成效段落是否含量化数据（百分比、金额、人次等）
- [ ] 总结段落是否回归理论体系，呼应开篇
- [ ] 附录是否包含教材依据、政策文件、学术文献
- [ ] 习近平文化思想关键言论是否自然嵌入，是否全部标注出处

### 8.3 本研双版本一致性检查
同时生成本科生和研究生两个版本时，确保：
- [ ] 核心事实（时间、地点、数据）一致
- [ ] 理论对接点一致（同一组习近平文化思想关键言论）
- [ ] 但叙事深度、分析维度、语言复杂度有明确差异
- [ ] 教学设计各有侧重：研究生偏分析论证，本科生偏理解践行

### 8.4 针对性修改流程
自检发现问题后，按以下优先级修改：
1. **事实错误**：优先修正所有数据、时间、引用原文错误
2. **结构缺失**：补全缺失模块（如缺少成效数据、缺少某个矛盾维度）
3. **理论脱节**：调整理论对接点，使案例实践与习近平文化思想言论更精准匹配
4. **表述优化**：优化句式、增强叙事逻辑、提升可读性

## 九、工作流程（完整版）

### 9.1 完整工作流
```
用户提供选题+角度+受众层次（本科/研究生/双版本）
    ↓
Step 1: 理论锚点对接表
    - 检索习近平文化思想关键言论，确定本案例将对接的3-5条核心表述
    ↓
Step 2: 联网检索素材
    - 围绕"选题关键词+地域+核心概念"进行多渠道检索
    - 优先获取：政策文件、官方数据、权威媒体报道、学术文献
    ↓
Step 3: 素材整理与真实性验证
    - 按"背景/困境/举措/成效"分类整理
    - 关键数据交叉验证（≥2个独立来源）
    - 习近平文化思想引用核验
    ↓
Step 4: 按模板撰写案例文本（分本科/研究生版本）
    - 先写研究生版（理论纵深），再基于同素材改写本科版（叙事直观）
    - 确保核心事实一致，叙事深度差异化
    ↓
Step 5: 模板符合性自检 + 修改
    - 对照8.2检查清单逐项自检
    - 针对发现的问题修改
    ↓
Step 6: 配套撰写教学设计（分本科/研究生版本）
    - 研究生版：学情分析偏理论思辨，讨论题偏辨析论证
    - 本科生版：学情分析偏认知特点，讨论题偏理解践行
    ↓
Step 7: 交付最终成果
    - 案例文本（本科版+研究生版）
    - 教学设计（本科版+研究生版本）
    - 素材汇编与真实性验证记录
```

### 9.2 各环节输入输出
| 步骤 | 输入 | 输出 |
|------|------|------|
| 1.理论锚点对接 | 选题+角度 | 理论锚点对接表（3-5条习近平文化思想关键言论+出处） |
| 2.素材检索 | 选题关键词 | 素材汇编（政策、报道、学术、数据） |
| 3.素材验证 | 素材汇编 | 经核验的结构化素材库（附验证说明） |
| 4.案例撰写 | 素材库+模板 | 案例文本初稿（本科+研究生双版本） |

### 9.3 检索关键词策略
- **核心词**：选题主题词（如"城市更新""湿地修复"）
- **地域词**：案例地点（如"上海崇明""杨浦228"）
- **理论词**：对应习近平文化思想的关键词（如"人与自然和谐共生""系统观念"）
- **组合方式**：`核心词+地域词` → `核心理论词+地域词` → `核心词+政策文件/学术研究`
