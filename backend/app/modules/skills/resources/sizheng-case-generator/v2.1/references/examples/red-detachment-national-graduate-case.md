# “洋为中用”——芭蕾舞剧《红色娘子军》的中西合璧之路
——以中央芭蕾舞团集体创作为例

一、摘要和关键词
【摘要】本案例以中央芭蕾舞团创作演出的革命现代芭蕾舞剧《红色娘子军》为分析样本，系统梳理其自1964年首演至今的跨时代创作历程。该剧在周恩来总理“革命化、民族化、群众化”改革方针指引下，面对西方芭蕾与中国革命题材之间形式与内容的深层张力，通过系统性艺术创新——改造舞蹈语汇（融入中国武术、戏曲、民间舞元素）、重构音乐体系（中西乐器融合、引入人声合唱）、重塑舞台美学（军装足尖形象颠覆王子公主叙事）——成功将芭蕾舞这一西方古典艺术形式转化为讲述中国革命故事、塑造中国英雄形象的表达载体。自1964年首演至今，该剧累计演出超过4000场，足迹遍布美国、英国、俄罗斯等20多个国家，2015年登陆纽约林肯中心并获《纽约时报》《经济学人》高度赞誉。《红色娘子军》的实践，生动诠释了习近平文化思想中“洋为中用、中西合璧、融会贯通”的核心要义，为社会主义文艺如何在开放中坚守主体性、在借鉴中实现创新提供了经典范本。

【关键词】洋为中用  中西合璧  红色娘子军  芭蕾舞剧  文化自信

二、案例背景
芭蕾舞剧《红色娘子军》的故事发生在二十世纪三十年代的中国海南岛。1931年5月1日，中国工农红军第二独立师第三团女子军特务连在海南省琼海市正式成立，百余位女战士在琼崖大地上书写了一段巾帼传奇。这支被毛泽东同志誉为“妇女解放运动之旗帜”的队伍，其战斗事迹在解放后被广泛传播。1961年，剧作家梁信根据真实历史素材创作了电影文学剧本《红色娘子军》，1962年由谢晋执导拍成彩色故事片，获得首届大众电影百花奖最佳故事片等多项大奖，一夜之间红遍全国。
然而，当文艺界酝酿将这部广受欢迎的电影改编为芭蕾舞剧时，一个尖锐的问题横亘眼前：芭蕾，这一孕育于14世纪意大利文艺复兴时期、繁荣于19世纪俄罗斯的西方古典艺术形式，其经典的审美范式——王子与公主的缠绵悱恻、白色纱裙下的轻盈足尖、优雅柔美的程式化动作——与中国的革命战争题材、工农兵英雄形象之间，是否存在不可调和的内在矛盾？如果强行嫁接，是“削足适履”还是“画虎类犬”？
1963年底，在周恩来总理的亲切关怀和直接推动下，问题找到了突破口。周总理在观看中央芭蕾舞团演出的《巴黎圣母院》后指出：“你们可以一边学习排演外国的古典芭蕾舞剧，一边创作一些革命题材的剧目。”时任文化部副部长林默涵随即组织讨论会，确定将电影《红色娘子军》改编为芭蕾舞剧，并成立了由李承祥、蒋祖慧、王希贤担任编导，吴祖强、杜鸣心、戴宏威、施万春、王燕樵担任作曲的集体创作班子。
1964年9月26日，芭蕾舞剧《红色娘子军》在北京天桥剧场首演，引发轰动。10月8日，毛泽东主席观看后题词：“革命是成功的，方向是对头的，艺术上也是好的。”此后，该剧于1970年被拍成彩色艺术电影在全国放映；1972年尼克松访华时，中方安排其观看《红色娘子军》，让西方世界首次通过芭蕾形式认识中国革命；1978年中国艺术团访美，2015年该剧正式登陆纽约林肯中心；截至2024年，累计演出超过4000场，足迹遍布20多个国家。
《红色娘子军》的诞生，标志着中国芭蕾艺术从“学习借鉴”迈向“自主原创”的历史性转折，也开启了西方古典艺术形式与中国革命内容深度融合的创造性实践。

三、遇到的困难
芭蕾舞剧《红色娘子军》的创作，从一开始就面临形式与内容、传统与创新、民族性与世界性之间的多重深层矛盾。
第一，艺术形式与革命内容的张力难题。芭蕾作为一种源自欧洲宫廷的艺术形式，经过几个世纪的沉淀，已形成一套高度程式化的审美规范：足尖技术、开绷直立、王子公主叙事、浪漫主义美学。而《红色娘子军》所要表达的，是中国土地革命战争中一群被压迫农奴翻身求解放的武装斗争故事，其情感基调是愤怒、抗争、牺牲与新生，与古典芭蕾所擅长的优雅柔美存在本质差异。
第二，深入生活与艺术提炼的平衡难题。革命历史题材要求创作者准确把握历史真实，但文艺作品又必须超越简单记录，进行艺术提炼。1964年2月，创作班子赴海南岛深入生活，采访当年娘子军连的老战士，探访老革命根据地，目睹了地主的水牢和刑具。白淑湘后来回忆，这些经历对塑造琼花这一形象至关重要。
第三，艺术创新与政治风险的边界难题。初排完成后，军区领导批评“只见‘娘子’不见‘军’”，指出演员身上还残留着古典芭蕾的柔美惯性，缺乏军人的刚健气质。此后全体演员赴山西大同某部队体验生活，学习走步、正步、刺杀、打枪，历时数周的军事化训练被白淑湘称为“脱胎换骨”。
第四，国际传播与文化解码的差异难题。《红色娘子军》走向世界后，外国观众面对一部完全不同于西方芭蕾传统的作品，其理解能力和文化背景构成了新的接受困境。如何让不同文化背景的观众跨越叙事隔阂，真正理解作品背后的精神内核，是国际传播中长期存在的挑战。

四、机遇与挑战
1. 发展机遇
一是党和国家领导人的直接推动。周恩来总理提出了创作革命题材芭蕾的构想，毛泽东主席题词肯定了该剧的价值。这种高层支持为艺术创新提供了宽松的制度空间。
二是已有电影作品的坚实基础。梁信的电影文学剧本和谢晋导演的电影版本已经深入人心，琼花、洪常青等人物形象家喻户晓，为舞剧改编提供了成熟的叙事框架。
三是集体创作的制度优势。该剧采用编导、作曲、舞美、表演多学科协作的集体创作模式，确保了艺术创新的多元视角和充分论证。
四是深入生活的创作传统。创作班子赴海南岛采风，从老战士冯增敏的故事中汲取人物原型，从诉苦大会的现场感受中找到了琼花参军的情感依据。
2. 现实挑战
一是艺术语言的根本性转换难题。如何将芭蕾的足尖技术与中国革命军人的战斗姿态相融合？编导蒋祖慧大量吸收了中国古典舞、京剧、武术的动作语汇——琼花的倒踢紫金冠和串翻身突破古典芭蕾的柔美程式，娘子军的大刀舞借鉴了中国武术的武舞元素，赤卫队的五寸刀舞吸收了广东英歌舞的节奏韵律。
二是音乐体系的跨文化融合难题。西方芭蕾音乐以交响乐团为主导，而《红色娘子军》需要在管弦乐的基础上融入竹笛、琵琶、芦笙等中国民族乐器，并开创性地引入人声合唱。
三是历史评价与经典化过程中的争议难题。《红色娘子军》在“文革”期间被树立为“样板戏”，其政治身份与艺术价值之间存在复杂的张力，如何在历史复杂性中准确把握其艺术价值是一个持续的理论与实践课题。

五、成效与推广
1. 艺术创新成效：芭蕾史上的“中国样本”
该剧开创了一系列芭蕾史上的“第一”：第一次用芭蕾演绎中国革命英雄传奇，芭蕾的主角第一次由女战士组成而非仙女公主，刀枪第一次作为道具出现在芭蕾舞台，交响乐与人声合唱第一次完整融合于芭蕾舞剧中。
2. 文化传播成效：从北京天桥到纽约林肯中心
该剧累计演出超过4000场，跨越半个多世纪仍长演不衰。国际传播方面，1972年尼克松访华时观看演出；1978年中国艺术团访美，玛莎·格雷姆盛赞其“非常有张力”；2009年首登巴黎歌剧院；2015年正式登陆纽约林肯中心，座无虚席，《纽约时报》称其为“一个革命性的舞台作品”，《经济学人》评价其“大步向前飞跃，讲述了一个积极进步的女性解放故事”；该剧足迹遍布20多个国家。2019年入选中国艺术研究院发布的“在《讲话》精神照耀下百部文艺作品”榜单。
3. 社会影响成效：超越艺术的文化符号
《红色娘子军》已超越一部舞剧的范畴，成为中华民族集体记忆的重要载体。剧中人物琼花和洪常青成为中国观众最熟悉的艺术形象之一。该剧培养了一代代芭蕾艺术家，仅“琼花”的饰演者就有六代——白淑湘、薛菁华、冯英、李宁、朱妍、邱芸庭等。
4. 国际认可成效：从“政治宣传”到“艺术经典”的话语转换
国际评论界对《红色娘子军》的评价经历了从"政治符号"到"艺术经典"的话语转换。意大利历史学教授玛丽尼拉评价："其价值和内涵已超越时代和意识形态的局限。"古巴舞蹈家阿隆索称赞："在芭蕾历史上第一次出现拿刀枪的足尖舞，你们太了不起了。"

六、案例总结
芭蕾舞剧《红色娘子军》的成功实践，深刻印证了习近平文化思想中关于"洋为中用、中西合璧"的核心论述。
1. “洋为中用、中西合璧”：艺术创新的根本路径
习近平在文艺工作座谈会上的讲话中指出："我们社会主义文艺要繁荣发展起来，必须认真学习借鉴世界各国人民创造的优秀文艺。只有坚持洋为中用、开拓创新，做到中西合璧、融会贯通，我国文艺才能更好发展繁荣起来。"《红色娘子军》正是这一论断的早期实践先声。
该剧没有因为芭蕾的"外国血统"而拒之门外，也没有因为要表现中国革命而抛弃芭蕾的形式。正如编导蒋祖慧所言："以芭蕾为主，尽量充分地运用芭蕾语汇，同时积极吸收本土特色，再加上中国民间韵律和服装、背景的特色，组合起来自然具有中国味道。"
2. "创造性转化、创新性发展"：文艺创新的方法论
习近平强调："传承中华文化，绝不是简单复古，也不是盲目排外，而是古为今用、洋为中用，辩证取舍、推陈出新，摒弃消极因素，继承积极思想，"以古人之规矩，开自己之生面"，实现中华文化的创造性转化和创新性发展。"《红色娘子军》对芭蕾的改造不是简单替换，而是创造性转化——将古典芭蕾的Arabesque姿势用于表现琼花的反抗意志，将中国戏曲的亮相融入舞剧叙事节点，实现了破法不悖法的艺术升华。
3. "两个结合"：更深层次的文化创造逻辑
习近平在文化传承发展座谈会上强调"两个结合"——把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合，是"我们已经成功的秘密武器"。《红色娘子军》将马克思主义关于人民创造历史的观点转化为舞台上的工农兵英雄形象，将中国共产党的革命叙事转化为可感可知的舞蹈语言，是"两个结合"在艺术领域的早期实践结晶。
4. "文化自信"：开放的底气与坚守的定力
习近平强调："文化自信，是更基础、更广泛、更深厚的自信，是更基本、更深沉、更持久的力量。"《红色娘子军》的成功，根本上源于创作者对自身文化的深厚自信。正如习近平所指出的："如果"以洋为尊"、"以洋为美"、"唯洋是从"，把作品在国外获奖作为最高追求，跟在别人后面亦步亦趋、东施效颦，热衷于"去思想化"、"去价值化"、"去历史化"、"去中国化"、"去主流化"那一套，绝对是没有前途的！"《红色娘子军》恰恰以反例证明了：只有坚守中华文化立场，大胆借鉴外来形式，才能实现真正有生命力的艺术创新。
