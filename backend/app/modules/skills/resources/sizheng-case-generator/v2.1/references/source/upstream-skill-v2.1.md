# 习近平文化思想课程思政案例生成技能

为《习近平文化思想》课程（本科生通识课，兼顾研究生思政课）生成配套思政案例，适用于上海大学担任该课程教学任务的教师。每个案例交付两份文档：**案例文本** + **教学设计**，按需分本科生版/研究生版。

## 触发条件

用户提供"选题+角度+受众层次（本科/研究生/双版本）"后启动。若用户只给选题，先追问角度与受众，或给出建议方案供确认。

## 案例分级体系（动笔前必须先定级）

所有案例分为三级，用户给选题后先判断级别，级别决定叙事重心：

| 级别 | 对象 | 叙事重心 |
|------|------|---------|
| **国家案例** | 全国性实践（总书记重要论述的发生地与考察点、国家战略工程、全国性文化工程） | 理论高度与普遍意义，凸显党的创新理论的全国性指导作用 |
| **上海市案例** | 上海贯彻落实习近平文化思想的实践（最佳实践地建设、城市文化治理、重大文化工程） | 治理逻辑与经验提炼，凸显地方实践的示范性 |
| **上海大学案例** | 上海大学师生参与文化建设、理论传播的实践 | 上大人的参与感，激发学生对学校的认同感 |

分级规则：
1. 国家案例与上海市案例是课程主体，数量上应占多数；上海大学案例服务于学校认同感教育，宜精不宜滥。
2. 一个案例可跨级（如上大师生参与上海市实践、上海市实践对接国家论述），须明确主归类，并在文本中如实区分各层级的角色，不混淆主体。
3. **上海大学案例必须实事求是**。只写可核实的事实（谁、以什么身份、做了什么、出品方或报道来源是什么），重点呈现上大人在传播、发扬、践行习近平文化思想方面所做的努力；严禁拔高阐释，如"深度参与顶层设计""全面参与""引领"等无出处的表述；学理分量靠被写者的学术身份与实际作为支撑，不靠形容词。身份信息（头衔、人才计划、学术兼职）须以学校官网等权威来源核实后写入，并在素材汇编中记录来源。
4. 案例文本中宜有明确的上大维度落点（如"举措与实践"下设"上大力量"小节，或举措分条中专列一条），本研双版本的上大表述保持事实一致。

## 核心工作流（七步，顺序不可颠倒）

1. **理论锚点对接表**：先确定本案例对接的 3-5 条习近平文化思想关键言论（精确原文+出处），再动笔。不预设教材章节。
2. **联网检索素材**：关键词组合 = 核心词+地域词 → 理论词+地域词 → 核心词+政策文件。优先级：政府官网 > 人民日报/新华社 > 学术期刊 > 一般报道。
3. **素材整理与真实性验证**：按"背景/困境/举措/成效"分类；关键数据至少两个独立来源交叉印证；总书记言论须与《习近平谈治国理政》等权威出版物逐字核对，不得改写、缩略、意译。
4. **撰写案例文本**：先写研究生版（理论纵深），再基于同素材改写本科版（叙事直观）。核心事实一致，深度差异化。
5. **模板符合性自检**：对照检查清单逐项核对（见下）。
6. **配套撰写教学设计**：研究生版学情分析偏理论思辨、讨论题偏辨析论证；本科生版偏认知特点与情感共鸣、讨论题偏理解践行。
7. **交付**：案例文本+教学设计（各版本）+ 素材汇编与真实性验证记录。

详细规范（选题原则、结构模块、行文风格、格式、检查清单、检索策略）见 `references/template-spec-v2.0.md`，写作前必读。

## 案例文本六模块结构

```
一、摘要和关键词（摘要150-250字；关键词3-5个：主题词+理论词+地域词）
二、案例背景（时空坐标→历史沿革→时代背景→典型意义；先纵向后横向）
三、遇到的困难（分条列出，每条含问题实质+两难性质+影响范围；必须有具体数据）
四、举措与实践（先理念转变后具体措施；措施与困难一一对应，形成问题—对策闭环）
五、成效与推广（分维度+量化数据+外部认证+可推广经验的名称化提炼）
六、案例总结（理论定位→逐个理论对接点展开：先引理论原文再结合案例分析→升华）
附录（教材依据1-2部+政策文件+学术文献/新闻报道2-4篇）
```

## 教学设计结构

```
一、教学说明（教学目的：知识/能力/价值三维目标；阅读思考题3-4道；课时安排90分钟）
二、教学文本内容
    （一）导语（1-2段情境导入）
    （二）教学内容描述（对应案例文本核心内容）
    （三）教学内容分析【教学要点】+【教学过程】+【教学方法】
    （四）思考讨论题（理解类/分析类/反思类/践行类）
三、附件（参考文献）
```

教学过程四段式：情境导入(10min)→案例剖析(20min)→理论解读(15min)→研讨升华(分组讨论+汇报+总结)。

研究生版教学设计另含：课前准备、学情分析、课程框架（理论重点/设计思路/总结点评要点）、教学流程（五环节90分钟）、教学反思与课后拓展。参见 228街坊研究生教学设计范例。

## 本研双版本差异（核心）

| 维度 | 研究生版 | 本科生版 |
|------|---------|---------|
| 摘要 | 200-300字，含理论框架 | 150-250字，概述背景举措成效 |
| 背景 | 历史沿革+制度语境 | 简明时空坐标+问题缘起 |
| 困难 | 矛盾多维交织，剖析制度性根源 | 实践层面两难选择 |
| 举措 | 制度创新、机制设计层面 | 操作层面"做了什么、怎么做" |
| 成效 | 理论贡献、制度意义 | 实践效果、社会反响 |
| 总结 | 理论—实践—理论闭环 | 思想启示、价值认同 |
| 教学设计 | 思辨与论证 | 理解与践行 |

篇幅参考：研究生案例文本约5000-6600字（228案例达1.1万），本科生案例文本约1900-2700字。

## 写作注意事项

1. 语言四性：学术性、政理性、叙事性、数据性。多用复句与"既……又……"关联结构；新旧对比、正反对比；关键位置必嵌数据。
2. 经验提炼要"名称化"，如"东滩模式""围割淹晒种调六字诀""151030机制""三个100%"。
3. 文件命名参照范例：`主题——副标题-研究生/本科生案例文本/思政教学设计.docx`。
5. 交付 Word 文档，修改补充内容以红色标出。
