# “生态保护优先”——上海崇明东滩湿地生态修复与生物多样性保护，打造长江口生态屏障

一、教学说明
（一）教学目的
本案例以上海崇明东滩湿地生态修复与生物多样性保护为背景，讲解上海崇明东滩湿地坚持生态保护优先、绿色发展的战略地位，分析统筹推进水、土、林、气、滩和生物多样性一体化保护进而提升生态系统多样性、稳定性、持续性的生态治理理论与实践。引导学生深刻理解习近平生态文明思想，掌握生态系统修复与生物多样性保护的原理，以及坚持山水林田湖草沙一体化保护和系统治理的系统观念的方法论，增强学生建设高品质生态环境和人与自然和谐共生美丽中国的理论自觉和实践自觉。
（二）阅读思考题
1.习近平总书记指出：“我们要像保护眼睛一样保护自然和生态环境，推动形成人与自然和谐共生新格局。”结合崇明东滩湿地的生态风光，谈谈自己的理解？
2.对于崇明东滩互花米草治理，曾有两种选择：一种是走化学修复的路子，见效快、周期短，却可能对底泥、水体和湿地本底带来后续影响；另一种是走人工修复的路子，投入更大，治理周期更长，却可以尽可能减少对原有生态系统的扰动。你会选择哪种方案？崇明东滩湿地生态恢复与重建开展了哪些实践？
3.“坚持系统观念”方法论在崇明东滩湿地生态系统功能修复与生物多样性保护中怎样体现的？
4.崇明东滩湿地生态恢复与重建为全国乃至世界生态治理提供了哪些有益经验？
（三）教学安排
本案例建议安排2课时（90分钟）。课前15分钟，学生预习案例材料，梳理上海崇明东滩湿地生态系统修复与生物多样性保护的核心要点，初步思考思考题；第一课时（45分钟）：情境导入（10分钟）、案例系统呈现（20分钟）、理论解读（15分钟）；第二课时（45分钟）：分组讨论（20分钟）、各组汇报交流（15分钟）、总结升华与行动引领（10分钟）。
二、教学文本内容
（一）导语
崇明岛是世界最大的河口冲积岛，素有“长江门户、东海瀛洲”的美称。崇明是“生态之岛”，拥有东滩国际重要湿地、东滩鸟类国家级自然保护区，是众多鸟类和野生动物的栖息地，特别是数以百万计的“东亚—澳大利西亚”国际候鸟的重要栖息地，被联合国环境规划署誉为“太平洋西岸难得的净土”。自2016年确立为世界级生态岛定位以来，崇明始终坚持以习近平生态文明思想为指导，坚守“生态立岛”不动摇，积极探索东滩湿地保护与修复路径，积极推进外来物种清除及生物多样性恢复工作，打造长江口生态屏障，形成了可复制的滨海湿地修复的“东滩模式”，成为人与自然和谐共生的典范。
（二）教学内容描述
1.上海崇明东滩湿地生态退化危机与修复诉求的时代背景
自2002年起，东滩湿地生态系统退化问题日益显现。外来物种互花米草入侵，其根系造成滩涂土壤板结，挤占本地物种海三棱藨草、芦苇生存环境，导致底栖生物锐减、候鸟食源匮乏，小天鹅等珍稀鸟类几近消失；海三棱藨草（候鸟核心食源）群落萎缩，芦苇沼泽碎片化，湿地初级生产力与食物网断裂；滩涂淤高、潮沟堵塞，潮汐水文节律失衡，水质净化与调蓄功能弱化；海平面上升，咸水入侵威胁湿地生境；鸟类栖息地质量恶化，迁徙水鸟种群数量显著下滑；生态系统与生物多样性监测、精细化及智慧化生态监管能力不足，等等。2007年4月，时任上海市委书记的习近平同志在崇明调研时指出，“我们要把崇明建设成为环境和谐优美、资源集约利用、经济社会协调发展的现代化生态岛区，实现崇明跨越式发展”，为崇明生态发展道路指明了方向。崇明大力培育经济社会持续健康发展的生态环境支撑点，将东滩生态资源作为最宝贵的发展要素，努力推进东滩河湖和湿地生态保护修复，推动生物多样性治理迈上新台阶。
2.上海崇明东滩湿地生态系统修复的理念与实践举措
（1）从“单一治理”到“系统功能重建”的修复理念
东滩湿地摒弃碎片化单一修复模式，以系统观念确立“生态系统功能优先、水文地貌为基、原生生物为本、过程动态调控”的核心理念，将湿地视作水文、土壤、植被、动物、微生物共生耦合完整系统，完善湿地内部物质循环、能量流动、信息传递生态链条。东滩将恢复栖息地供给、食源生产、水文调节、固碳四大核心功能作为主要导向，而非仅追求植被覆盖度，并以“围、割、淹、晒、种、调”六字诀为核心。同时，依据潮汐节律、土壤盐度、高程梯度，构建多生境、异质性、可调控的湿地景观。东滩湿地修复工作推进水、土、林、气、滩和生物多样性一体化保护，实现从“单一治理”到“系统功能重建”修复理念的彻底转变。
（2）湿地生态系统修复的实践举措
第一，综合治理入侵物种。东滩修复区开展基础性、控制性工程建设的核心技术是“围、割、淹、晒、种、调”六字诀。一是“围”，修筑生态围堤（长约50公里），开挖随塘河，建可控涵闸，隔离入侵区，实现水文独立调控。二是“割”，在生长季（5-8月），使用机械刈割地上植株，阻断光合作用，削弱根系活力。三是“淹”，刈割后蓄水淹浸（水深30-50cm，持续3-6个月），抑制种子萌发与根系呼吸，致植株死亡。四是“晒”，在非生长季，排水露滩，致使土壤干裂，破坏互花米草根系，同时促进本土植物种子萌发。五是“种”，在治理区补植海三棱藨草、芦苇等本土物种，快速抢占生态位，防止二次入侵。六是“调”，动态调控水位、盐度，适配本土植物生长，抑制互花米草再生。
第二，重建原生植被群落。聚焦食源功能与栖息地结构，重建本土植被群落，如，海三棱藨草修复（核心食源）。通过研发种子播种、球茎苗移栽、自然斑块复壮技术，解决了“萌发率低、定居难”问题。2023年实施《海三棱藨草种群生态修复技术规程》，为长江口湿地修复提供了科学规范。根据该《规程》，加大海三棱藨草在堤外自然系统当中的种植力度，促进泥质滩涂的形成，并利用自然潮汐不断加大滩涂地貌的自然塑造，为过境的鸻鹬类鸟类提供了优质的栖息场所和良好的“餐厅”。加强对芦苇沼泽的修复，形成高草隐蔽带，满足鸟类栖息、繁殖需求。
第三，重构水文地貌系统。通过地形重塑、水系连通、水位调控，恢复潮汐水文节律，构建“深水区—浅水区—潮滩—沼泽”梯度生境。对地形进行微改造，形成高低错落、干湿交替的地貌格局，满足不同鸟类取食、栖息需求。修复潮沟网络，实现水系连通。还采用智能水位调控。由此形成相对封闭、水位可调控管理的修复区及相对独立且可调控的生境单元，为植食性鸟类提供了优质的栖息地和食源地。
第四，提升生物多样性。全面实施生物多样性保护战略与行动计划。一是底栖生物恢复。通过降低滩涂高程、增加水体交换、投放螺类或贝类，恢复泥螺、缢蛏、蟹类等底栖生物，为鸻鹬类提供优质食源。二是鸟类栖息地优化。如，食源区，在浅水区（水深< 30cm）种植海三棱藨草，保障种子和底栖生物双重食源；栖息区，利用芦苇丛、生境岛屿提供隐蔽空间，深水区（水深> 1m）供雁鸭类游憩。从丰富鸟类栖息地多样化角度，构建鸻鹬类、雁鸭类、鹤类三类水鸟的主要栖息地，营造生境岛屿、漫滩、开阔水域、沙洲、水稻田、潮沟等多样化的生活环境。同时进行监测管护。强化科技赋能，构建“智慧湿地”管理体系，实时掌握种群动态。引入珍稀物种，优化食物链结构，提升生态系统稳定性。
第五，加强生态红线管控。实行生态空间分类管控，对一类（禁止建设，如东滩鸟类保护区等）、二类（严格管控，如重要湿地等严控建设与污染排放）的生态空间实行刚性管控，对三类、四类空间实行“弹性应对”。加强外来物种管控，提升生物安全监管水平。持续加强自然保护地、生态保护红线两类重要区域的生态保护修复统一监管，建立健全生态保护红线生态破坏问题监督机制。重点打击非法采砂（石）、捕捞、设立码头、挤占河（海）岸、挤占湿地等违法违规行为。保护长江口滩涂湿地资源，持续打好长江“十年禁渔”持久战。加强巡护管理，筑牢生态防线。
第六，开展科学研究。聚焦江海交汇形成的独特河口湿地生态系统和迁徙物种保育，立足崇明东滩湿地生态系统长期定位监测研究，努力提高野生动物资源调查与监测、鸟类环志与彩色旗标系放、野生动物疫源疫病监测预警、野外巡护技术以及退化湿地修复和重建等研究水平。
第七，推进管理创新和协同创新。东滩湿地保护区将工程修复与科研监测、长效管护结合起来，推进管理创新。推进跨部门、跨学科、跨区域湿地协同治理创新，联动林业、水利、环保、科研院所，整合资金、技术、人才资源，形成“政府主导、科技支撑、公众参与”的湿地保护修复协同机制。
第八，重视宣传教育。讲好东滩故事，传递东滩声音。创新科普教育宣传方式，构建科普教育交流合作平台，为增进社会各界对自然保护、湿地保护和迁徙物种保育的科学认识，培养民众的生态文明意识发挥重要作用，也为中小学素质教育活动、企业社会责任拓展等提供服务平台。
3.上海崇明东滩湿地生态系统功能修复与生物多样性保护取得的成效
在栖息地方面，重现“候鸟天堂”。修复区鸟类密度大幅提升，每年过境候鸟超百万只。截止2024年，在崇明湿地占全球种群数量1%以上的水鸟种数稳定在12种以上，鸟类种数增加到380余种。在水文与水质方面，“天然净化器”激活。湿地蓄水量大幅增加，水体交换增强，水质优化，为洄游鱼类提供优质产卵育幼环境。外来入侵物种蔓延趋势得到有效遏制，湿地植被生物量显著提升。崇明东滩湿地支撑城市生态质量，获“中国天然氧吧”“中国气候宜居城市”等国家级荣誉称号，2024年7月被列入《世界遗产名录》，成为上海首个世界自然遗产地。
4.上海崇明东滩湿地生态系统功能修复与生物多样性保护可复制、可推广的好经验、好做法
崇明东滩湿地生态治理，为全国和世界湿地修复与生物多样性保护事业提供了有益经验和智慧。如，创造性提出“围、割、淹、晒、种、调”的综合治理方案，取得了显著效果，为全国和世界互花米草的生态治理提供了可供复制的“东滩模式”。再如，各方担当作为，汇聚力量，形成合力，推动保护区的生态保护、科学研究和科普宣传等向前发展，为生态治理提供了可推广的好经验、好做法。
（三）教学内容分析
【教学要点】
要点一：生态系统功能修复与生物多样性保护是习近平生态文明思想的重要内容。自然是生命之母，生物多样性是人类赖以生存和发展的基础，是地球生命共同体的血脉和根基，人与自然是生命共同体，应像保护眼睛一样保护自然和生态环境，促进人与自然和谐共生。生态系统保护和修复是保障生物多样性的基础工程，是满足人民群众对良好生态环境殷切期盼的重要途径，也是践行绿水青山就是金山银山理念、实现人与自然和谐共生的重要举措。上海崇明东滩湿地生态恢复与生物多样性保护，是习近平生态文明思想在上海城市生态治理中的生动实践。
要点二：崇明东滩湿地生态修复与生物多样性保护体现出系统观念方法论。东滩湿地坚持系统观念，用普遍联系的、全面系统的、发展变化的观点观察和分析生态环境，把握生态发展规律。如，从“植被修复”到“系统功能重建”；工程修复、科研监测、长效管护三位一体的管理方式；“政府主导、科技支撑、公众参与”的湿地保护修复协同机制，等等。全面提升了当地生态系统的多样性、稳定性、持续性。
要点三：形成可复制可推广的好经验、好做法。崇明东滩湿地生态恢复与重建，实现了自身从“退化湿地”到“世界遗产地”的蝶变，恢复了湿地核心生态功能，探索出一条人与自然和谐共生的滨海湿地保护修复之路，为全国滨海湿地、河口湿地生态治理提供有益经验，为全球湿地修复与生物多样性保护事业提供了中国智慧与中国方案。
【教学过程】
本案例教学采用“情境导入—案例剖析—理论解读—研讨升华”四段式结构。
第一阶段（情境导入)：播放习近平总书记关于人与自然是生命共同体的重要讲话、上海崇明岛生态风光特别是东滩湿地风光短片或视频，展示崇明世界级生态岛发展指标包括湿地、生物多样性保护等类别（至2035年目标值），直观呈现崇明自然生态样态及发展目标。抛出引导问题：“为什么总书记提出‘我们要像保护眼睛一样保护自然和生态环境？’”“上海东滩湿地生态恢复与重建在上海城市发展中的地位和价值？对于全国乃至世界生态治理提供了哪些有益经验？”激活学生问题意识，为后续案例剖析与理论学习奠定基础。
第二阶段（案例剖析）：讲解上海崇明东滩湿地生态退化危机与修复诉求的时代背景，以及修复的途径和成效。其中，针对湿地生态系统退化问题，系统讲解“系统功能重建”修复理念、“水文—土壤—植被—动物—微生物”耦合系统，以及“围、割、淹、晒、种、调”六字诀综合治理技术。通过数据、图片等案例细节的展示，让学生把握上海崇明东滩湿地生态恢复与重建及生物多样性保护的成功实践，为理论解读与研讨提供支撑。
第三阶段（理论解读）：紧扣案例内容，深入解读习近平生态文明思想的相关内容，重点阐释“人与自然和谐共生”理念、“统筹山水林田湖草沙系统治理”方法、“生物多样性保护”举措等。
第四阶段（研讨升华）：组织学生围绕思考题展开分组讨论，每组聚焦一个核心问题，结合案例内容、理论知识与自身生活实际，交流观点。教师总结案例，深刻分析上海崇明东滩湿地生态修复与生物多样性保护所蕴含的习近平生态文明思想，以及可复制、可推广的经验及启示。引导青年学生培育人与自然是生命共同体的生态意识，掌握人与自然和谐共生的理念、方法和方略，守护地球家园、建设美丽中国。
【教学方法】
1.案例教学法：以上海崇明东滩湿地生态修复与生物多样性保护实践为案例，将习近平生态文明思想和习近平总书记关于湿地保护的重要指示精神与上海生态文明实践相结合，增强教学生动性、针对性和说服力，帮助学生更好理解习近平生态文明思想的理论内容与实践要求。
2.问题导向法：围绕教学目标设计思考题，引导学生带着问题学习、思考、讨论，激发学生主动探究意识，培养学生分析问题、解决问题的能力。
3.小组研讨法：组织学生分组讨论、汇报交流，鼓励学生发表不同观点、相互启发借鉴，培养学生团队协作能力、批判性思维能力和语言表达能力，实现思想碰撞与认知升华。
4.调查研究法：组织学生深入崇明东滩湿地一线，了解第一手实际资料并加强研学，进一步深化课堂理论学习。
（四）思考讨论题
1.崇明区相关负责人介绍说，“生态环境好不好，动植物最有发言权。”请结合案例，谈谈自己的理解？
2.谈谈崇明东滩生态恢复与重建创造性提出的“围、割、淹、晒、种、调”综合治理方案的启示及意义？
3.崇明东滩湿地生态修复与生物多样性保护，蕴涵习近平生态文明思想哪些内容？
4.结合案例，青年学生应如何践行人与自然和谐共生的生态价值观？
