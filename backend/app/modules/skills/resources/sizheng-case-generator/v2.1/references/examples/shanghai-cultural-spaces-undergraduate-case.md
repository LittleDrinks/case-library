# 把最好的资源留给人民
# ——上海文化新空间建设让城市成为艺术品
## ——以浦东美术馆与"一江一河"滨水空间为例

# 一、摘要和关键词

【摘要】本案例讲述上海文化新空间建设的故事。在"人民城市人民建，人民城市为人民"理念指引下，上海把小陆家嘴滨江核心区最好的一块土地用来建浦东美术馆，把黄浦江、苏州河两岸一百多公里岸线打通还给市民，把美术馆、博物馆的专业资源送到市民家门口。从浦东美术馆的"一排1座"，到前滩休闲公园的旧砖步道，再到"社会大美育课堂"和"家门口的好去处"，上海让整座城市成为一件属于人民的艺术品，生动体现了把最好的资源留给人民的价值追求。我们学校的文学院院长刘旭光教授应邀走进《看见人文之城》的镜头，把城市之美的道理讲给全市观众听。

【关键词】人民城市  文化新空间  浦东美术馆  一江一河

# 二、案例背景

黄浦江、苏州河是上海的母亲河，但在很长时间里，两岸被码头、仓库和工厂占据，市民"看得见江，走不近江"。陆家嘴高楼林立、寸土寸金，却一度缺少人文气息和艺术底蕴。2019年11月，习近平总书记在上海考察时提出"人民城市人民建，人民城市为人民"，为上海的城市建设指明了方向。2024年2月，上海出台《上海市建设习近平文化思想最佳实践地行动方案》，部署九大行动、30项重点工程，文化新空间建设成为其中一项重要内容。在《看见人文之城》系列短视频第六集《让城市成为艺术品》中，我们学校的文学院院长刘旭光教授走进浦东美术馆、前滩休闲公园，解读了这座城市让艺术融入日常的奥秘。他说，文化新空间既是物理空间，又是交往空间，还是精神空间，文化空间让城市本身变成了艺术品。

# 三、遇到的困难

第一，黄金地块为谁而留。小陆家嘴滨江核心区最后一块宝地，面朝黄浦江与外滩，多家开发商表示不惜重金也要拿下。是卖地建楼，还是留下建美术馆？选择后者，意味着放弃巨额的土地收益，还要投入超过13亿元建设资金（不含土地成本）。

第二，滨江岸线如何打通。黄浦江从杨浦大桥到徐浦大桥45公里，横跨5个区20个街镇，沿线有轮渡码头、环卫码头，还有部门和企业的"专用"岸线，断点堵点众多，市民想沿江走通并不容易。

第三，文化空间如何"活"起来。场馆建好只是第一步，如果"重建设、轻运营"，就会"有场馆、无内容"。如何让普通市民特别是孩子们都能亲近艺术，让空间不仅"好看"而且"灵动"，是更大的考验。

# 四、举措与实践

第一，统一规划、整体营造。上海把文化空间建设纳入城市发展的顶层设计，形成重大文化设施、区域文化活力中心、社区乡村商圈文化新空间的多层级格局，让文化空间遍布全城、就在身边。

第二，把最好的资源留给人民。2021年7月8日，浦东美术馆在这块被网友称为"一排1座"的宝地上正式开馆。美术馆建筑主体占地1.3万平方米，设有13个展厅。它坚持周一不闭馆、常年开放夜场到晚九点，方便上班族下了班也能看展。管理团队说，"以人民为中心"是浦东美术馆的出发点。

第三，还江于民、还河于民。2017年年底，黄浦江45公里滨江公共空间贯通开放；2020年年底，苏州河中心城区42公里岸线贯通；如今"一江一河"贯通里程已超过100公里。前滩休闲公园2016年免费开放，总面积约26.64万平方米，沿黄浦江岸线约1778米，绿化率高达66%。最特别的是园内的红砖步道，用的是中粮仓库的旧砖。孩子们在黄金沙坑里建造"专属王国"，白领在骑行栈道上追风，老人在望江驿歇脚看书，昔日冷清的江岸成了人人可享的公共客厅。

第四，让美育走进日常。上海实施"社会大美育计划"，2025年全市143个"社会大美育课堂"开展艺术普及教育活动8500多场，惠及580多万人次；市民艺术夜校让年轻人"白天上班、晚上学艺"。浦东美术馆五年举办350余场公共教育活动，向近400所学校发出邀约，近2万名师生走进展厅上美育课，还与英国泰特美术馆联合发起"美普绘"少儿艺术家培养计划。

第五，以文化带动城市活力。浦东美术馆集美术馆、观景平台、展演空间、文化地标的功用于一身，观众看罢展览，还能在"镜厅"和露台上欣赏上海的文化天际线。开馆以来，它与英国泰特美术馆、法国卢浮宫博物馆、美国大都会艺术博物馆等十余家全球顶尖机构合作，五年推出近30场重量级展览，累计参观人次近400万。看展带动了周边餐饮、休闲、教育等行业发展，"来上海看美展"成为上海新的城市名片。

第六，上大人的身影。《看见人文之城》系列短视频由上海市委宣传部等单位联合出品，邀请知名社科专家出镜，解读《上海市建设习近平文化思想最佳实践地行动方案》部署的各项实践，第六集的主讲人正是我们学校的文学院院长刘旭光教授。刘旭光教授长期研究美学和艺术学理论，曾获评教育部青年长江学者。在镜头前，他把"文而化之""以文化人"这些听起来深奥的道理，讲成了观众听得懂的城市故事，让"让城市成为艺术品"成为许多人记住的一句话。上大人正在用自己所学参与这座城市的文化建设，把习近平文化思想讲给更多人听。

# 五、成效与推广

文化新空间建设让上海的城市面貌与市民生活悄然改变。空间上，"一江一河"贯通里程超过100公里，滨水休闲道达200多公里，黄浦江滨江累计建成公共空间1200公顷。人气上，2024年度"一江一河"到访群众超过1.68亿人次，举办各类主题活动超500场。美育上，"社会大美育课堂"年惠及580多万人次，浦东美术馆开馆五年参观人次近400万。品牌上，"来上海看美展"成为城市文化品牌，上海7个门类11部作品在第十七届精神文明建设"五个一工程"评选中获奖，数量创历史新高。"把最好的资源留给人民"的"浦美样本"、"还江于民"的"一江一河"实践、"家门口的好去处"，正在成为其他城市可以学习借鉴的经验。

# 六、案例总结

上海文化新空间建设的实践，深刻印证了习近平文化思想的真理力量。习近平总书记指出，"人民城市人民建，人民城市为人民。在城市建设中，一定要贯彻以人民为中心的发展思想，合理安排生产、生活、生态空间，努力扩大公共空间，让老百姓有休闲、健身、娱乐的地方，让城市成为老百姓宜业宜居的乐园"。把最美的江岸留给市民，把最好的地块建成美术馆，正是人民城市理念最直观的体现。习近平总书记还指出，"城市是人集中生活的地方，城市建设必须把让人民宜居安居放在首位，把最好的资源留给人民"。这一重要论述在上海变成了看得见、摸得着的现实。

习近平总书记强调，要"着眼满足人民群众多样化、多层次、多方面的精神文化需求，提升文化服务和文化产品供给能力，增强人民群众文化获得感、幸福感"。从世界级美术馆到社区里的美育课堂，从滨江步道到望江驿，上海的文化供给覆盖了不同年龄、不同职业、不同区域的人群，让文化获得感成为市民的日常体验。习近平总书记还指出，"历史文化是城市的灵魂，要像爱惜自己的生命一样保护好城市历史文化遗产"。前滩公园的旧砖步道、杨浦滨江的工业遗存，正是城市记忆在新时代的延续。

让城市成为艺术品，靠的不是盖几座造型奇特的地标建筑，而是让人民成为城市的主人。当每一个普通人都能在家门口遇见美、感受美、创造美，城市便拥有了最动人的艺术品格。我们学校的老师走进镜头讲述城市之美，也提醒每一位上大学子，人民城市的建设有每个人的位置，学问做得好，同样可以服务这座城市、感染身边的人。这是上海给我们的启示，也是新时代青年参与人民城市建设应当牢记的价值坐标。
