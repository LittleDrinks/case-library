# 把最好的资源留给人民
# ——上海文化新空间建设让城市成为艺术品
## ——研究生思政课教学设计

# 一、教学目标

## 1. 知识目标

（1）掌握习近平文化思想中关于人民城市理念、公共文化服务体系建设、历史文化遗产保护传承的核心论述，理解"人民城市人民建，人民城市为人民""把最好的资源留给人民""历史文化是城市的灵魂"等重要论述的文本依据与理论内涵。

（2）熟悉《上海市建设习近平文化思想最佳实践地行动方案》九大行动、30项重点工程的总体框架，掌握"一江一河"滨水空间贯通与浦东美术馆建设运营的关键事实、核心数据与实践逻辑。

（3）理解文化新空间"既是物理空间，又是交往空间，还是精神空间"的三重属性理论，把握"以文化人""以文惠民""以文兴业"三者之间的内在关联。

## 2. 能力目标

（1）提升理论联系实际的分析能力，能够运用习近平文化思想的核心观点解读城市文化空间建设的实践案例，实现理论与实践的双向阐释。

（2）增强辩证思维能力，能够辩证分析商业逻辑与公共价值、空间约束与需求增长、设施建设与内涵运营、文脉保护与城市更新等多重关系。

（3）培养从微观案例提炼宏观制度逻辑的研究能力，能够从上海文化新空间建设中归纳可复制、可推广的超大城市文化治理经验。

## 3. 价值目标

（1）深刻认识人民城市理念对城市空间价值排序的重构意义，理解中国特色社会主义城市的人民性本质，增强制度自信。

（2）体认"把最好的资源留给人民"的发展观、价值观、政绩观，树立以人民为中心的发展思想。

（3）坚定文化自信，自觉担当新时代新的文化使命，将个人成长融入人民城市与文化强国建设的实践进程。

（4）通过上海大学文学院院长刘旭光教授应邀主讲《看见人文之城》第六集的实例，认识高校学者在党的创新理论大众化传播中的角色，增强作为上大人的学术使命感与学校认同感。

# 二、课前准备

## 1. 硬件条件

多媒体教室（配备投影仪、音响、电脑、网络），支持视频播放与线上资料查阅。

## 2. 软件与资料准备

（1）教材文献。《习近平文化思想学习纲要》（学习出版社、人民出版社2024年版）相关章节，《习近平新时代中国特色社会主义思想概论》相关章节。

（2）案例材料。上海文化新空间建设案例文本、核心数据图表（"一江一河"贯通里程、到访人次，浦东美术馆展览数量、参观人次、公共教育数据等）、实景图片（浦东美术馆"镜厅"与观景露台、前滩休闲公园红砖步道、杨浦滨江工业遗存新旧对比图等）。

（3）视频资料。《看见人文之城》系列短视频第六集《让城市成为艺术品》（上海大学文学院院长刘旭光教授解读，5分钟左右），可辅以浦东美术馆五周年回顾短片。

（4）辅助材料。课堂讨论问题清单、小组汇报记录表、课后拓展阅读文献目录。

## 3. 学生预习准备

（1）研读《习近平文化思想学习纲要》相关章节，梳理人民城市理念与文化建设的核心论述，标注重点与疑问。

（2）通读案例文本，梳理上海文化新空间建设的背景、五重矛盾、六项举措、"上大力量"与成效数据，初步思考讨论问题。

（3）有条件的同学可实地走访浦东美术馆、前滩休闲公园或所在区域的文化新空间，获取第一手观感。

# 三、教学对象

## 1. 授课对象

一年级硕士研究生。

## 2. 学情分析

（1）知识基础。学生已系统学习新时代中国特色社会主义理论的基础内容，对习近平文化思想有初步认知，但对人民城市理念与文化建设的空间维度关注较少，缺乏将文化理论落实到城市空间实践的分析经验。

（2）认知特点。学生具备较强的理论思辨能力和文献检索能力，关注城市化、空间正义、文化消费等现实议题，多数有在上海学习生活的切身体验，对滨江空间、文化场馆有直观印象，乐于结合亲身经验展开讨论。

（3）学习需求。学生渴望在抽象理论与具体实践之间建立联结，希望通过典型案例掌握"以理论解读实践、以实践印证理论"的方法，并能提炼出具有学术价值的真问题，服务于论文选题与研究设计。

（4）潜在不足。部分学生易将案例学习停留在"成就描述"层面，难以穿透到价值排序重构、治理机制创新的深层逻辑；对城市研究中"文化导向的城市更新"等西方理论脉络了解有限，比较分析的视野有待打开。

# 四、课程框架

## 1. 理论重点

（1）人民城市理念的城市观。"人民城市人民建，人民城市为人民"深刻回答了城市建设发展依靠谁、为了谁的根本问题。城市空间的公共性是人民城市的本质规定，"一江一河"从生产岸线到公共客厅的转型，是这一理念最直观的空间呈现。

（2）文化建设着眼于人、落脚于人的供需观。满足人民群众多样化、多层次、多方面的精神文化需求，要求文化供给在布局上分层分类、在送达上直达基层、在内容上全龄覆盖，社会大美育与公共文化配送构成可及性建设的两翼。

（3）"历史文化是城市的灵魂"的文脉观。城市更新必须在保护中发展、在发展中保护，工业遗存与历史建筑的活化利用，检验的是城市对自身记忆的敬畏与再造能力。

（4）"以文化人"的文化观。文化新空间既是物理空间，又是交往空间，还是精神空间，"文而化之"通过空间的中介得以实现，文化建设的最终指向是人的精神气质与城市品格的熔铸。

（5）文化事业与文化产业相统一的发展观。文化新空间作为文化综合体，兼具公益属性与产业带动功能，"以文兴业"与"以文惠民"在文旅商体展融合中实现统一。

## 2. 设计思路

本课坚持理论引领、案例具象、问题导向、价值升华，以上海文化新空间建设为典型样本，紧扣习近平文化思想核心论述，构建"理论—实践—理论"闭环教学。以"为谁而留、为谁而开"的空间价值之问为导入线索，呈现浦东美术馆选址决策与"一江一河"贯通攻坚两组关键实践；以五重矛盾与六项举措的结构化对照为分析框架，训练学生把握问题与对策的对应逻辑；以中西比较与机制分析为思辨抓手，引导学生穿透"成就叙事"，抵达价值排序重构与治理体系创新的深层逻辑；以人民城市理念与文化强国战略的关联为升华落点，强化学生的价值认同与使命担当。同时，本案例定位为上海大学案例，以刘旭光教授应邀主讲《看见人文之城》第六集为切入点，将"上大力量"融入教学，激发学生的学校认同感。

## 3. 总结点评要点

（1）理论契合度。考察学生能否精准对接五条理论重点，做到用案例实践佐证理论、用理论框架解读案例，避免理论与实践"两张皮"。

（2）逻辑辩证性。考察学生能否辩证分析商业逻辑与公共价值、贯通开放与利益格局、设施建设与内涵运营、文脉保护与城市更新的关系，避免片面化、绝对化。

（3）实践关联性。考察学生能否从微观案例中提炼宏观制度逻辑，理解上海经验对全国超大城市文化空间建设的借鉴意义与适用边界。

（4）价值导向性。考察学生能否深刻认同人民城市理念与"把最好的资源留给人民"的价值追求，理解中国特色社会主义城市的人民性本质。

（5）创新思考。鼓励学生提出差异化观点与延伸性课题，如数字技术对文化新空间的影响、文化空间的社会分层效应等，点评其学术潜力。

# 五、课堂讨论问题

1. 浦东美术馆"一排1座"的选址决策中，商业逻辑与公共价值发生了直接冲突。请结合案例材料，分析"把最好的资源留给人民"对城市资源配置逻辑意味着什么？与西方城市"文化导向的城市更新"路径相比，二者的价值分野与制度条件何在？

2. "一江一河"贯通涉及跨区协调、部门岸线腾退与既有利益格局调整，上海以"滨江党建"和区域化党建联席会议破解条块壁垒。请从治理现代化的角度评价这一机制的有效性与可推广性，它同单纯依靠行政命令或市场补偿的方式有何不同？

3. 刘旭光教授提出，文化新空间"既是物理空间，又是交往空间，还是精神空间"。请运用这一三重属性框架，分析你熟悉的一处城市文化空间（校园、社区、场馆皆可），论证"以文化人"在空间中的实现机制及其限度。

4. 从"工业锈带"到"生活秀带"，上海对杨浦滨江工业遗存、前滩旧砖步道的活化如何体现"在保护中发展、在发展中保护"？对照"历史文化是城市的灵魂"的重要论述，谈谈城市更新中"整体营造"的方法论意义及其对新城新区文化建设的启示。

5. 《看见人文之城》系列短视频邀请高校学者解读最佳实践地建设实践，上海大学文学院院长刘旭光教授应邀主讲第六集。请结合本案例，分析高校学者在党的创新理论大众化传播中可以发挥何种作用？学术阐释与宣传阐释的结合应当把握怎样的边界，才能既保证学理深度又避免拔高失实？

# 六、教学流程

（总时长90分钟）

## 1. 课程导入（10分钟）

教学方法为情境导入法、设问法，组织形式为全班集体教学。

播放《看见人文之城》第六集《让城市成为艺术品》片段，随后展示两组图片对比。一组是黄浦江两岸"工业锈带"的历史影像与今日"生活秀带"的实景照片，一组是陆家嘴摩天楼群的天际线与浦东美术馆"一排1座"的滨江位置图。设问导入，"寸土寸金的城市之心，为什么要把最贵的一块地留给一座美术馆？曾经被码头和围墙占据的江岸，凭什么能成为亿人次到访的公共客厅？"由此点明本课主题，以上海文化新空间建设为例，探究习近平文化思想与人民城市理念在城市空间中的实践逻辑，明确学习目标。

## 2. 案例展示（15分钟）

教学方法为视频教学法、图文讲解法，组织形式为全班集体教学。

教师结合课件完整梳理案例脉络，即背景（人民城市理念提出与最佳实践地行动方案出台）→困难（商业逻辑与公共价值等五重矛盾）→举措（顶层设计、留最好的资源、还江于民、美育直达基层、文化综合体、文脉活化，以及刘旭光教授主讲第六集所体现的上大力量）→成效（空间、人气、美育、品牌、经验五个维度），逐一标注关键数据（45公里与100公里贯通里程、1.68亿人次、近400万参观人次、13亿元投入、580万美育人次等），帮助学生快速建立案例的整体图景，为理论剖析奠定事实基础。

## 3. 案例剖析（25分钟）

教学方法为问题导向法、理论联用法、启发式教学，组织形式为全班集体互动。

围绕五条理论重点，结合案例细节逐一剖析。一是对接人民城市理念，从"一江一河"从生产岸线到公共客厅的转型，解读城市空间公共性的价值意蕴。二是对接"把最好的资源留给人民"，从"一排1座"选址、13亿元投入与周一不闭馆的运营细节，解读城市发展价值排序的深刻调整。三是对接"着眼满足人民群众多样化、多层次、多方面的精神文化需求"，从多层级文化空间格局与社会大美育体系，解读文化供给侧的结构性改革。四是对接"历史文化是城市的灵魂"，从工业遗存活化与旧砖步道的"绣花"功夫，解读在保护中发展的更新方法论。五是对接"以文化人"，从物理空间、交往空间、精神空间的三重属性，解读文化新空间的深层功能逻辑。每一对接均先呈现理论原文，再还原案例细节，最后引导学生作机制层面的追问。

## 4. 小组讨论（25分钟）

教学方法为小组讨论法、合作探究法，组织形式为4至5人一组分组讨论。

将学生分为5至6组，每组推选一名组长与一名汇报人，分发讨论问题清单与记录表。各小组围绕四个课堂讨论问题中的至少一个展开20分钟深度讨论，要求结合理论文本、案例数据与自身生活经验，梳理核心观点、支撑依据与创新思考。教师巡视各组，适时点拨，引导学生从"成就描述"深入到"机制分析"。随后各组汇报人依次作3分钟汇报，其他小组可补充或质疑，形成观点碰撞。

## 5. 总结升华（15分钟）

教学方法为归纳总结法、升华法，组织形式为全班集体教学。

教师结合总结点评要点，对各组汇报逐一简要点评，肯定亮点、指出不足。继而提炼案例核心逻辑，上海文化新空间建设以价值排序的重构为前提，以规划、治理、运营的机制创新为支撑，实现了人民城市理念与习近平文化思想在空间领域的交汇落地。最后回归理论，重申"人民城市人民建，人民城市为人民""把最好的资源留给人民"的深刻意涵，联系文化强国战略与青年学子的城市生活体验，鼓励学生以专业所长参与人民城市建设，在空间实践中读懂中国式现代化的城市文明新形态。

# 七、教学反思与课后拓展

## 1. 教学反思

（1）教学亮点。案例选取贴近学生在沪生活经验，"为谁而留、为谁而开"的问题设计具有张力，能有效激发探究兴趣；五重矛盾与六项举措的结构化呈现，训练了问题与对策的对应分析能力；理论对接环节坚持"原文先行、案例印证、机制追问"三步走，理论与案例的融合度较高。

（2）潜在不足。案例信息量大，涉及规划、治理、运营多个维度，部分学生可能难以在课堂时间内消化全部数据；讨论问题理论密度较高，对跨学科背景的学生构成一定挑战；对文化新空间建设中的争议性议题（如公益与商业的边界）展开不足。

（3）改进方向。课前发放案例要点清单与思维导图，帮助学生快速把握脉络；视学情将讨论问题分层设置，兼顾不同学科背景；增设"反方视角"环节，引导学生批判性思考案例的限度与争议，避免单向度的成就叙事。

## 2. 课后拓展

（1）完整研读案例文本与附录文献，结合《习近平文化思想学习纲要》相关章节，撰写500字左右的学习心得，梳理"理论—实践—理论"的对应关系。

（2）调研身边的一处文化新空间（美术馆、图书馆、社区文化活动中心、滨江驿站、商圈文化空间等），运用"物理空间、交往空间、精神空间"三重属性框架撰写实地观察报告，分析其"以文化人"的实现机制与改进空间，字数不少于1500字。

（3）围绕"超大城市文化空间建设的人民性"或"文化导向的城市更新的中国路径"选题，检索国内外文献，撰写一篇小型文献综述，为课程论文或学位论文选题做准备。
