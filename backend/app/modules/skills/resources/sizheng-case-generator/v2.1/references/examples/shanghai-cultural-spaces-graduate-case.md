# 把最好的资源留给人民
# ——上海文化新空间建设让城市成为艺术品
## ——以浦东美术馆与"一江一河"滨水空间为例

# 一、摘要和关键词

【摘要】本案例以上海文化新空间建设为分析样本，以浦东美术馆和"一江一河"滨水公共空间为核心考察对象，从人民城市理念与习近平文化思想在城市空间实践中的交汇处切入，考察上海从"工业锈带"到"生活秀带"、从功能导向到人文导向的城市转型逻辑。案例梳理了超大城市文化空间建设中商业逻辑与公共价值、空间约束与需求增长、条块分割与贯通开放、设施建设与内涵运营、文脉保护与城市更新五重矛盾，以及上海以统一规划整体营造、优质资源留给人民、还江于民分层供给、以文兴业融合运营、活化文脉在保护中发展为路径的系统破解之策。上海文化新空间建设生动诠释了"人民城市人民建，人民城市为人民"的城市观、"把最好的资源留给人民"的价值观和"以文化人"的文化观，为建设习近平文化思想最佳实践地提供了鲜活的空间样本，也为超大城市文化治理提供了可复制、可推广的经验。案例同时聚焦上海大学文学院院长刘旭光教授应邀主讲《看见人文之城》第六集的传播实践，呈现高校学者参与党的创新理论大众化传播的上大力量。

【关键词】人民城市  文化新空间  以文化人  浦东美术馆  一江一河  上大力量

# 二、案例背景

2019年11月2日，习近平总书记在上海考察时来到杨浦滨江公共空间杨树浦水厂滨江段，对杨浦区科学改造滨江空间、打造群众公共休闲活动场所的做法表示肯定，提出了"人民城市人民建，人民城市为人民"重要理念。在此之前，2017年年底，黄浦江沿岸已基本实现从杨浦大桥到徐浦大桥45公里滨江公共空间贯通开放；2020年年底，苏州河中心城区42公里滨水岸线也实现基本贯通开放。2021年7月8日，由法国建筑师、普利兹克奖得主让·努维尔设计的浦东美术馆在小陆家嘴滨江核心区正式向公众开放，为陆家嘴天际线增添了一处面向全球、连接艺术与人的崭新坐标。2023年10月，全国宣传思想文化工作会议正式提出习近平文化思想。2024年2月，上海市委常委会审议通过《上海市建设习近平文化思想最佳实践地行动方案》，出台九大行动、30项重点工程，明确提出推进重大文化设施和多样化区域文化活力中心建设，培育更多文化新空间和休闲好去处，把最好的文化资源留给人民。此后，由中共上海市委宣传部、中共上海市委网信办、中共上海市委外宣办、上海市社会科学界联合会与文汇报社联合出品的《看见人文之城》系列短视频，邀请知名社科专家和实践地建设者，全景式、沉浸式解读《行动方案》九大行动、30项重点工程的精彩实践，阐释文化建设的内在肌理，提炼文化实践的一般规律。系列第六集《让城市成为艺术品》中，上海大学文学院院长刘旭光教授走进浦东美术馆、前滩休闲公园，在扑面而来的艺术氛围中解读上海文化新空间建设的内在肌理，引起广泛社会反响。

上海因水而生、因水而兴。黄浦江、苏州河一纵一横，既是上海的"母亲河"，也曾经是码头、仓库、工厂密布的生产岸线。自2002年启动黄浦江两岸综合开发以来，上海持续推进沿岸功能转型；2010年上海世博会加速了这一进程；《上海市城市总体规划（2017-2035年）》进一步明确，要建设"卓越的全球城市，令人向往的创新之城、人文之城、生态之城"，文化被置于城市发展更加突出的位置。在这一转型图景中，文化新空间的建设成为关键抓手。近年来，上海布局打造了一系列新的文化新地标新空间，包括重大文化设施、区域化文化活力中心、社区乡村商圈文化新空间等，形成了多层级的文化新空间格局。

在这幅从"工业锈带"到"生活秀带"的转型图景中，浦东美术馆与"一江一河"滨水空间构成了观察人民城市理念的两个典型切片。前者回答"寸土寸金的城市之心为谁而留"的问题，后者回答"城市的滨水岸线为谁而开"的问题。二者共同指向文化新空间建设的价值原点，即把最好的资源留给人民。

# 三、遇到的困难

上海文化新空间建设，面临的是超大城市转型中多重矛盾相互交织的复杂局面。

第一，商业逻辑与公共价值的矛盾。小陆家嘴滨江核心区最后启动开发的一块"宝地"，面朝黄浦江与外滩，毗邻东方明珠塔，商业价值极高。2017年美术馆开工建设前，多家开发商看中这块地，表示不惜重金也要拿下。据光明日报等媒体报道，浦东新区的态度是"多少钱的项目都不打算卖，就是要留下来给老百姓建个美术馆"。选择建美术馆，意味着放弃可观的土地收益与商业回报；为建造一座世界一流水准的专业美术馆，不含土地成本，陆家嘴集团投入超过13亿元。这块地为谁而留，考验的是城市的发展观、价值观与政绩观。

第二，空间约束与需求增长的矛盾。上海是拥有2400余万常住人口的超大城市，土地资源高度稀缺，文化设施供需长期存在结构性矛盾。人民对美好生活的向往总体上已经从"有没有"转向"好不好"，文化需求呈现多样化、多层次、多方面的特点。上海现有500余家文博场馆、剧场剧院和A级旅游景区，每年举办近4万场演出、约2000场展览，供给规模不可谓不大，但高品质文化空间布局不均衡、可达性不足的问题依然存在，市民日益增长的精神文化需求对文化空间的数量、品质与可及性提出了更高要求。

第三，条块分割与贯通开放的矛盾。黄浦江从杨浦大桥到徐浦大桥45公里，横跨上海5个区20个街镇，沿线既有轮渡码头、环卫码头、海事码头等市政设施，还有一些部门和企业的"专用"岸线。条块壁垒、机制束缚，断点堵点众多。实现岸线公共空间的贯通开放，本质上是对既有利益格局和治理体系的重塑，"还江于民"说来容易，做起来寸寸用心。

第四，设施建设与内涵运营的矛盾。文化新空间建设不是简单的场馆工程。文化新空间既是物理空间，又是交往空间，还是精神空间，倘若"重建设、轻运营"，就可能陷入"有场馆、无内容""有流量、无沉淀"的困境。如何让空间从"好看"走向"灵动"，让高雅艺术与烟火气在空间中交织，让市民不仅进得来，而且留得住、有共鸣，是比工程建设更难的课题。

第五，文脉保护与城市更新的矛盾。黄浦江、苏州河沿岸留存了大量工业遗存和历史建筑，仅"一江一河"沿岸就有约33万平方米历史建筑和工业遗存需要在"十四五"期间完成保护和更新利用。大拆大建会割断城市记忆，原封不动又难以满足现代功能需求，"在保护中发展、在发展中保护"对更新理念与技术路径提出了很高要求。

# 四、举措与实践

## （一）理念之变，从功能城市到人文之城

上海文化新空间建设的深层逻辑，首先是一场理念之变。刘旭光教授指出，文化的使命是文而化之，是通过一系列包含着精神内涵的活动，滋养人、培养人，营造社会氛围，熔铸市民与整个城市的精神气质；文化新空间的建构为文化活动的展开提供了可能，它是"以文化人"的载体，但又超出了物理意义，既是物理空间，又是交往空间，还是精神空间。在这一理念指引下，上海形成了建设文化新空间的三点创新思路。一是通过统一规划、整体营造，实现"以文化人"的顶层设计，把文化空间的功能性与城市区域规划、市民生活相结合。二是让文化新空间建设成为"以文惠民"的载体，体现人民性，从人民的需求出发，分层分类进行文化空间的区域规划与联动，全面满足人民的文化需求。三是让文化新空间成为"以文兴业"的渠道，以文化综合体带动区域协同发展。

## （二）实践举措

第一，统一规划、整体营造，构建多层级文化新空间格局。上海将文化新空间布局纳入城市发展的顶层设计，逐步形成重大文化设施、区域化文化活力中心、社区乡村商圈文化新空间等多层级格局。《上海市建设习近平文化思想最佳实践地行动方案》以九大行动、30项重点工程为纲，将公共文化惠民便民行动、城市文脉赓续鼎新行动、文创产业聚变跃升行动等落到实处。"十四五"期间，黄浦江沿岸加快推进近20处高等级公共设施建设，新增滨水贯通岸线约20公里，新建滨水大型绿地及公共空间约400公顷，浦东美术馆、上海图书馆东馆、上海博物馆东馆、世博文化公园及上海大歌剧院等重大文化设施相继落成或推进，世界级滨水文化设施带初具规模。

第二，把最好的资源留给人民，让文化地标立于城市之心。面对商业开发的巨大诱惑，浦东新区区委、区政府与陆家嘴集团决定放弃部分经济效益，在小陆家嘴滨江核心区建设高品质公共美术馆，使之成为浦东滨江打造"世界城市会客厅"的重要载体。这块被网友称为"一排1座"的土地上，美术馆建筑主体占地1.3万平方米，总建筑空间面积近4万平方米，设有13个展厅，可展览总面积超过1万平方米。在运营上，浦东美术馆坚持周一不闭馆、常年开放夜场至晚九点，以契合陆家嘴区域人群的作息特点；管理团队明确表示，"以人民为中心"是浦东美术馆的出发点，立志成为以观众为中心的美术馆，通过精彩的艺术展览和艺术活动触动人心。

第三，还江于民、还河于民，让滨水空间成为城市公共客厅。上海以党建引领破解贯通难题，创设"滨江党建"城市基层党建工作品牌，依托区域化党建联席会议和共建联建协议，打通沿线断点堵点。2017年年底黄浦江45公里、2020年年底苏州河42公里岸线相继贯通开放；截至2025年，"一江一河"岸线贯通里程已超过100公里，漫步、跑步、骑行等休闲道达到200多公里。2022年1月1日，《上海市黄浦江苏州河滨水公共空间条例》施行，为滨水公共空间的高起点规划、高标准建设、高品质开放和高水平管理提供法治保障。以前滩休闲公园为例，这座2016年1月免费向市民开放的公园总面积约26.64万平方米，沿黄浦江岸线约1778米，绿化率高达66%，园内红砖步道以中粮仓库的旧砖铺设，望江驿为市民游客提供歇脚休憩的场所，与友城公园等连成约2.3公里的前滩亲水景观通道，成为"生态前沿"主题下的都市绿色生活空间。孩子们在滨江亲水平台上穿梭奔跑，都市白领在骑行栈道上追风而过，老人在树荫下看书小憩，曾经的"养在深闺人未识"变成了人人可享的城市公共客厅。

第四，分层分类、直达基层，让美育融入市民日常生活。上海深入实施"大博物馆计划""大美术馆计划""社会大美育计划"，推动专业艺术资源转化为社会美育资源。2025年，全市143个"社会大美育课堂"累计开展艺术普及教育活动8593场，惠及人次逾580万；市民文化节全年开展线上线下活动4万余项，参与人次近2000万；公共文化配送全年配送各类文化活动9.3万场，惠及市民2099万人次；"家门口的好去处""美术新空间""儿童友好城市阅读新空间"持续扩容，融入15分钟公共文化服务圈。浦东美术馆五年累计开展公共教育活动350余场，线上线下吸引近47万人次参与，向近400所学校发出邀约，近2万名师生走进展厅开展校外美育实践，并与英国泰特美术馆联合发起"美普绘"少儿艺术家培养计划，为孩子们提供走向世界的舞台。

第五，以文兴业、融合运营，让文化空间成为文化综合体。浦东美术馆将美术馆、观景平台、室内展演空间、文化地标等功能聚集在一起，人们在这里不仅可以享受文化艺术，还可以在"镜厅"和观景露台上感受上海文化天际线与城市魅力。开馆以来，浦东美术馆与英国泰特美术馆、法国卢浮宫博物馆、法国奥赛博物馆、美国大都会艺术博物馆等十余家全球顶尖机构合作，五年推出近30场重量级展览，累计参观人次近400万；其中"缔造现代：来自巴黎奥赛博物馆的艺术瑰宝"大展在130天内吸引逾百万人次观展，成为现象级文化事件。文化空间的发展带动促进了周边区域休闲消费、餐饮、教育、健康等行业的协同发展，"来上海看美展"成为上海城市文化新品牌，文旅商体展融合发展的格局初步形成。2024年度，"一江一河"到访群众超过1.68亿人次，举办各类主题活动超500场，滨水空间的人气活力持续攀升。

第六，活化文脉、整体营造，在保护中发展。上海坚持把历史文化遗产保护传承融入滨水空间更新，杨浦滨江创建生活秀带国家文物保护利用示范区，推进约6万平方米历史建筑修缮及改造利用；民生码头12栋工业遗存开展整体功能策划与分期建设；前滩休闲公园以旧砖铺路的"绣花"功夫，让工业记忆融入市民的日常风景。刘旭光教授认为，古镇要"洋气"，"洋气"需要美化，美化即是艺术化；城市更新的关键在于整体营造，必须让在地民众拥有实实在在的获得感。他强调，未来文化新空间建设应进一步聚焦"要求之新"与"建构之新"，通过文商旅体展农深度融合，将功能性与人民性有机结合，并积极动员社会力量，引入能够提升民众审美趣味的多元活动；只有让高雅艺术与烟火气在空间中交织，才能让空间不仅"好看"而且"灵动"，真正成为活化人文资源、培育新型生活方式、提升人民群众获得感与城市软实力的生动例证。

## （三）上大力量，高校学者参与党的创新理论大众化传播

《看见人文之城》系列短视频是上海阐释习近平文化思想、展示最佳实践地建设成果的官方传播产品。上海大学文学院院长刘旭光教授应邀主讲第六集。作为文艺学、美学和艺术学理论专家，他是2019年度教育部青年长江学者、国家社科基金艺术学重大项目首席专家，兼任中华美学学会常务理事、上海美学学会副会长（据上海大学官网教师简介）。镜头前，他以美学研究的学术积累为依托，把"文而化之"的文化观、"物理空间、交往空间、精神空间"的三重属性框架与"以文化人、以文惠民、以文兴业"的创新理念，转化为面向公众的通俗阐释，使"让城市成为艺术品"成为观众听得懂、记得住的城市文化命题。

这一参与的意义可以从三个层面实事求是地加以理解。其一，就传播环节而言，学者的深度参与使政策叙事获得了学理支撑，让党的创新理论以更可感的方式"飞入寻常百姓家"。其二，就高校职能而言，高校是学习研究宣传习近平文化思想的重要阵地，学者走出书斋、走进镜头，把论文写在城市大地上，是高校履行社会服务职能、服务城市文化建设的具体行动。其三，就上海大学而言，文学院教师以美学专长参与城市文化的公共阐释，是上大人在传播、发扬、践行习近平文化思想方面所作努力的真实缩影。人民城市人民建，学者的专业参与本身即是"人人参与"的生动注脚。

# 五、成效与推广

其一，空间格局之变。从黄浦江45公里贯通到"一江一河"贯通里程超过100公里，黄浦江滨江累计建成公共空间1200公顷，滨水漫步、跑步、骑行等休闲道达200多公里，近20处高等级公共设施沿江布局，重大文化设施、区域文化活力中心、社区乡村商圈文化新空间的多层级格局基本成形。

其二，人气活力之聚。2024年度"一江一河"到访群众超过1.68亿人次，举办各类主题活动超500场；浦东美术馆开馆五年累计参观人次近400万，开馆初期日均客流量即保持在3500人次，国际国内重大赛事、特色文旅活动频繁上演，滨水空间成为市民游客休憩放松、旅游打卡的首选目的地。

其三，美育浸润之效。143个"社会大美育课堂"年开展艺术普及教育活动8593场、惠及逾580万人次；浦东美术馆公共教育活动线上线下参与近47万人次，近2万名师生进馆开展美育实践；上海原创、上海出品的文艺精品持续涌现，2024年12月第十七届精神文明建设"五个一工程"评选揭晓，上海7个门类11部作品获奖，数量创历史新高。

其四，城市品牌之势。"来上海看美展"成为城市文化品牌，浦东美术馆成长为上海链接全球艺术资源的重要枢纽，以及中国美术馆专业化、国际化、公共化发展的鲜明样本。据上海市人大相关视察报告，"一江一河"滨水区正逐步成为贯彻落实人民城市重要理念的最佳实践区和示范样板区。

其五，可推广经验之提炼。"把最好的资源留给人民"的"浦美样本"、"还江于民"的"一江一河"实践、党建引领的贯通机制、多层级文化新空间格局与文化综合体运营模式，为全国超大城市文化空间建设提供了可复制、可推广的经验，也为全球滨水城市更新贡献了中国方案。

# 六、案例总结

上海文化新空间建设，是习近平文化思想与人民城市理念在城市空间领域交汇互构的生动实践。文化新空间之"新"，不在于建筑的崭新，而在于理念之新、机制之新，在于城市空间价值排序的深刻重构。

其一，"人民城市人民建，人民城市为人民"的城市观。习近平总书记2019年11月2日在上海考察时指出，"人民城市人民建，人民城市为人民。在城市建设中，一定要贯彻以人民为中心的发展思想，合理安排生产、生活、生态空间，努力扩大公共空间，让老百姓有休闲、健身、娱乐的地方，让城市成为老百姓宜业宜居的乐园"。上海把最优质的滨水岸线从生产空间、专用岸线还原为公共空间，让曾经"看得见江、走不近江"的城市重新向水而开，正是对人民城市理念的直接回应。城市空间的生产、生活、生态功能因此被重新安排，公共性成为空间的第一属性。

其二，"把最好的资源留给人民"的价值观。习近平总书记2020年11月12日在浦东开发开放30周年庆祝大会上指出，"城市是人集中生活的地方，城市建设必须把让人民宜居安居放在首位，把最好的资源留给人民"。浦东美术馆"一排1座"的选址与"多少钱的项目都不打算卖"的定力表明，城市之心最稀缺的空间资源应当服务于人的精神生活，而非单纯服务于资本增值。这是城市发展价值排序的深刻调整，也是社会主义城市区别于资本主导型城市的本质规定。

其三，"着眼满足人民群众多样化、多层次、多方面的精神文化需求"的供需观。习近平总书记在二十届中央政治局第十七次集体学习时强调，要始终坚持文化建设着眼于人、落脚于人，"着眼满足人民群众多样化、多层次、多方面的精神文化需求，提升文化服务和文化产品供给能力，增强人民群众文化获得感、幸福感"。上海分层分类进行文化空间的区域规划与联动，以社会大美育课堂、公共文化配送、家门口的好去处构建全龄全域的文化供给体系，使文化服务的可及性与精准性大为提升，文化获得感成为可感可及的日常经验。

其四，"历史文化是城市的灵魂"的文脉观。习近平总书记2014年2月25日在北京市考察工作时指出，"历史文化是城市的灵魂，要像爱惜自己的生命一样保护好城市历史文化遗产"，要"处理好城市改造开发和历史文化遗产保护利用的关系，切实做到在保护中发展、在发展中保护"。从杨浦滨江的工业遗存到前滩公园的旧砖步道，上海以整体营造和精细化"绣花"功夫，让城市记忆成为可感可用的公共文化资源，实现了老地方与新空间的迭变共生。

其五，"以文化人、以文育人"的文化观。习近平总书记强调，要"努力用中华民族创造的一切精神财富来以文化人、以文育人"。文化新空间之为"新"，正在于它超越了物理意义，成为交往空间与精神空间。市民在观展、漫步、阅读、交流之中涵养审美趣味，城市在文化活动的持续展开中熔铸精神气质。文化新空间由此成为"文而化之"的当代载体，文化建设着眼于人、落脚于人获得了空间形态的支撑。

"让城市成为艺术品"，其真义不在于天际线的奇观化，而在于人民性的空间展开。当世界级美术馆立于寸土寸金的滨江"一排1座"，当旧砖铺就的步道通向江畔的万家灯火，当市民在家门口与美相遇，城市本身便成为一座属于人民的大型公共艺术品。参与这场空间变革的，不仅有党委政府、建设者与运营者，也有以专业所长介入公共阐释的学界力量，上海大学文学院的学者走进镜头讲述城市之美，让更多人看懂了身边的人民城市。这正是上海建设习近平文化思想最佳实践地、打造自信自强文化样本的空间注脚，也是中国式现代化城市文明新形态的生动例证。
