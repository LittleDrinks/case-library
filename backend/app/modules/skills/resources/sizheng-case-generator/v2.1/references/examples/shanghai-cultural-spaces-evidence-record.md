# 素材汇编与真实性验证记录
## "让城市成为艺术品"案例写作支撑材料

# 一、理论锚点对接表

本案例对接习近平文化思想关键言论共5条，全部经权威来源逐字核对，未作改写、缩略或意译。

1. "人民城市人民建，人民城市为人民。在城市建设中，一定要贯彻以人民为中心的发展思想，合理安排生产、生活、生态空间，努力扩大公共空间，让老百姓有休闲、健身、娱乐的地方，让城市成为老百姓宜业宜居的乐园。"出处为2019年11月2日习近平总书记在上海考察杨浦滨江公共空间杨树浦水厂滨江段时的讲话，见中国政府网2019年11月3日《习近平：人民城市人民建，人民城市为人民》，人民网、央广网等多家权威媒体均可印证。

2. "城市是人集中生活的地方，城市建设必须把让人民宜居安居放在首位，把最好的资源留给人民。"出处为2020年11月12日习近平总书记在浦东开发开放30周年庆祝大会上的讲话，见央广网"每日一习话"栏目及人民日报相关报道。

3. "历史文化是城市的灵魂，要像爱惜自己的生命一样保护好城市历史文化遗产。"出处为2014年2月25日习近平总书记在北京市考察工作时的讲话，见人民网理论频道、中国共产党新闻网。

4. "着眼满足人民群众多样化、多层次、多方面的精神文化需求，提升文化服务和文化产品供给能力，增强人民群众文化获得感、幸福感。"出处为2024年10月28日习近平总书记在二十届中央政治局第十七次集体学习时的讲话，另见《加快建设文化强国》（《求是》2025年第8期）。相同表述亦见于2020年10月29日党的十九届五中全会第二次全体会议讲话、2021年8月17日中央财经委员会第十次会议讲话，本案例采用政治局集体学习版本并标注该出处。

5. "努力用中华民族创造的一切精神财富来以文化人、以文育人。"出处为2014年2月24日习近平总书记在十八届中央政治局第十三次集体学习时的讲话，见人民网理论频道。

# 二、关键事实与数据核验表

以下关键数据均经至少两个独立来源交叉印证，来源以政府官网、人民日报、新华社、中国新闻网为优先。

1. 黄浦江两岸45公里滨江公共空间贯通（杨浦大桥至徐浦大桥）时间为2017年年底，苏州河中心城区42公里岸线贯通为2020年年底。来源为《上海市"一江一河"发展"十四五"规划》（沪府发〔2021〕17号，上海市人民政府官网）、人民日报2022年11月3日《一江一河：把最好的资源留给人民》、上海市住建委2025年11月发布的视察报道。三个来源一致。

2. "一江一河"岸线贯通里程已超过100公里，滨水休闲道达200多公里；2024年度"一江一河"到访群众超过1.68亿人次，举办各类主题活动超500场。来源为上海市住建委网站2025年11月12日报道（2025年度人大代表集中视察活动），为官方口径。

3. 《上海市建设习近平文化思想最佳实践地行动方案》于2024年2月2日经上海市委常委会审议通过，出台九大行动、30项重点工程。来源为人民日报2024年4月15日《上海多措并举用好红色资源》、上海2024年十大新闻（上观新闻）。九大行动名称依据人民网上海频道2024年11月28日报道，即党的创新理论定向领航行动、"党的诞生地"红色文化传承弘扬行动、城市精神品格固本培元行动、主流舆论凝识聚力行动、城市文脉赓续鼎新行动、公共文化惠民便民行动、文创产业聚变跃升行动、国际传播重塑重构行动、文化发展牵引赋能行动。

4. 浦东美术馆2021年7月8日开馆，由让·努维尔设计，陆家嘴集团投资建设运营；建筑主体占地1.3万平方米，总建筑空间面积近4万平方米，13个展厅；开馆五年累计推出近30场重量级展览，累计参观人次近400万；与英国泰特美术馆、法国卢浮宫博物馆、法国奥赛博物馆、美国大都会艺术博物馆等机构合作；"缔造现代：来自巴黎奥赛博物馆的艺术瑰宝"大展130天内吸引逾百万人次；五年累计开展公共教育活动350余场，线上线下吸引近47万人次参与，向近400所学校发出邀约，近2万名师生走进展厅。来源为上海市文化和旅游局官网2026年7月8日《5年30场大展累计400万观众，一座美术馆重塑上海滨江文化图景》与中国新闻网上海2026年7月9日《浦东美术馆迎来开馆五周年》，两来源一致。开馆初期日均客流3500人次，来源为人民网上海频道2021年7月27日报道。

5. 陆家嘴集团为建设浦东美术馆投入超过13亿元（不含土地成本）；该地块曾有开发商不惜重金求地，浦东决定"多少钱的项目都不打算卖，就是要留下来给老百姓建个美术馆"。来源为光明日报"新时代文化地标"专栏报道《上海浦东美术馆：黄浦江畔的文艺港湾》（网络转载见网易新闻），与人民网2021年7月27日报道中徐而进"放弃一些经济效益，建设一个体现上海城市精神的高品质美术馆，奉献给市民、奉献给城市"的表述相互印证。注，前一条引语的直接出处为光明日报专栏稿，案例文本中以"据光明日报等媒体报道"作限定表述。

6. 前滩休闲公园2016年1月免费开放，总面积约26.64万平方米，沿黄浦江岸线约1778米，绿化率66%，红砖步道以中粮仓库旧砖铺设，有望江驿，与友城公园等连成约2.3公里亲水景观通道。来源为浦东发布（浦东新区政府新闻办）微信推送、中国新闻网、新浪新闻等多家来源，数据一致。

7. 2025年上海市143个"社会大美育课堂"累计开展艺术普及教育活动8593场，惠及人次逾580万；市民文化节全年开展线上线下活动4万余项，参与人次近2000万；公共文化配送全年9.3万场，惠及2099万人次。来源为"上海发布"2025年10月31日推送与上海市徐汇区政府网站2026年3月27日转载的上海市公共文化建设工作会议报道，两来源一致（后者表述为"累计开展艺术普及教育近9000场、服务受众逾580万人次"，为四舍五入口径）。

8. 上海现有500余家文博场馆、剧场剧院和A级旅游景区，每年举办近4万场演出、约2000场展览。来源为人民日报2024年4月15日《上海多措并举用好红色资源》。

9. "十四五"期间"一江一河"沿岸约33万平方米历史建筑和工业遗存保护更新利用、黄浦江沿岸新增滨水贯通岸线约20公里、新建滨水大型绿地及公共空间约400公顷、加快推进近20处高等级公共设施建设。来源为《上海市"一江一河"发展"十四五"规划》。

10. 《上海市黄浦江苏州河滨水公共空间条例》2022年1月1日施行。来源为人民日报2022年11月3日报道（2021年底通过）与上海市住建委报道（2022年1月1日实施），一致。

11. 第十七届精神文明建设"五个一工程"评选中，上海7个门类11部作品获奖，数量创历史新高。来源为上海2024年十大新闻（上观新闻）。

12. 刘旭光教授（上海大学文学院院长）关于"文化的使命是文而化之""文化新空间三重属性""以文化人、以文惠民、以文兴业三点创新理念"及"古镇要洋气、美化即是艺术化、城市更新关键在整体营造"等论述，均引自《看见人文之城》系列短视频第六集《让城市成为艺术品》（中共上海市委宣传部、中共上海市委网信办、中共上海市委外宣办、上海市社会科学界联合会与文汇报社联合出品）的官方发布文案，为用户提供的一手素材。

13. 刘旭光教授系文艺学、美学和艺术学理论专家，获评2019年度教育部青年长江学者，为国家社科基金艺术学重大项目首席专家，兼任中华美学学会常务理事、中国文艺理论学会和中外文艺理论学会理事、上海美学学会副会长。来源为上海大学官网教师简介页（shu.edu.cn/info/1609/75570.htm），为校方权威来源。《看见人文之城》系列定位为"邀请知名社科专家和实践地建设者，全景式、沉浸式解读《上海市建设习近平文化思想最佳实践地行动方案》九大行动、30项重点工程的精彩实践"，来源为该系列官方发布文案（文汇报社等发布渠道），两处表述均用于案例文本"上大力量"部分，未作引申。

# 三、存疑事项与处理说明

1. 《看见人文之城》第六集的具体播出日期未能从权威来源确证。上海发布微博显示该系列于10月26日至11月4日每日更新一集，但年份未见明确标注。案例文本与附录中均不标注该视频的具体播出日期，仅以"推出第六集"表述，避免年代错误。

2. 光明日报《上海浦东美术馆：黄浦江畔的文艺港湾》一文的准确刊发日期未获取原文核实，"多少钱的项目都不打算卖"一语的直接发言主体在转载文本中表述为"浦东决定"，故案例文本采用"据光明日报等媒体报道，浦东新区的态度是"的限定表述，不落到具体个人。

3. 上海常住人口表述为"2400余万"，采用概数口径，与上海市统计局公布数据量级一致，未使用精确数字以免年度口径出入。

4. "一江一河"到访群众1.68亿人次、主题活动超500场为2024年度数据，出自上海市住建委2025年11月发布的官方报道，为单一权威来源（人大视察活动通稿），但其发布主体为政府官网，可信度高，予以采用并标注年度。

5. 教学设计中"社会大美育课堂"2025年数据（8593场、580万人次）在本科生案例文本中按"8500多场、580多万人次"的约数表述，以兼容"近9000场"的另一种官方四舍五入口径。

# 四、写作与格式说明

本案例按《思政案例模板规范》撰写，含研究生版与本科生版案例文本及配套教学设计共四份文件。双版本核心事实、理论对接点完全一致，叙事深度差异化。本研双版本中浦美五年参观人次、贯通里程、美育数据等关键数字已逐一比对一致。

按案例分级体系（国家案例、上海市案例、上海大学案例），本案例归类为上海大学案例。上海市文化新空间建设实践构成案例主体，上大维度以文学院院长刘旭光教授应邀主讲《看见人文之城》第六集为支撑。上大力量部分仅写入可核实事实（出镜主讲、出品方与系列定位、经校方官网确认的学术身份），不作"深度参与""全面参与"等拔高阐释。
