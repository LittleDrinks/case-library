# 芭蕾舞剧《红色娘子军》：理解洋为中用

一、摘要和关键词
【摘要】本案例以中央芭蕾舞团创作演出的革命现代芭蕾舞剧《红色娘子军》为分析样本，阐述该剧如何以西方芭蕾艺术形式成功讲述中国革命故事。该剧自1964年首演至今，累计演出超过4000场，足迹遍布20多个国家。《红色娘子军》的诞生，是习近平文化思想中洋为中用、中西合璧理念的生动实践，展现了中国文化自信与开放包容的辩证统一。

【关键词】洋为中用  中西合璧  红色娘子军  文化自信

二、案例背景
芭蕾舞剧《红色娘子军》的故事发生在二十世纪三十年代的中国海南岛。1931年5月1日，中国工农红军第二独立师第三团女子军特务连在海南省琼海市正式成立，百余位女战士在琼崖大地上进行了艰苦卓绝的革命斗争。这支队伍被毛泽东同志誉为“妇女解放运动之旗帜”。
1961年，梁信创作电影文学剧本《红色娘子军》，1962年由谢晋执导拍成彩色故事片，获得首届百花奖最佳故事片等多项大奖，红遍全国。当文艺界酝酿将其改编为芭蕾舞剧时，一个尖锐的问题摆在面前：芭蕾这一西方古典艺术形式，如何与中国革命战争题材相结合？
1963年底，周恩来总理提出"你们可以一边学习排演外国的古典芭蕾舞剧，一边创作一些革命题材的剧目"。这一指示直接促成了《红色娘子军》的创作。1964年9月26日首演，10月8日毛泽东主席题词肯定。
截至2024年，该剧累计演出超过4000场，足迹遍布20多个国家。

三、艺术创新的突破性举措
《红色娘子军》的艺术创新，体现在舞蹈语汇、音乐体系、舞台美学三个层面。
第一，舞蹈语汇的创造性转化。编导蒋祖慧创造性地融合了多种艺术传统。琼花的倒踢紫金冠和串翻身突破古典芭蕾的柔美程式，融入中国古典舞的技巧张力；娘子军的大刀舞吸收了中国武术武舞的元素，刚劲有力；赤卫队的五寸刀舞借鉴了广东英歌舞的节奏韵律。蒋祖慧总结道：以芭蕾为主，充分运用芭蕾语汇，同时积极吸收本土特色，再加上中国民间韵律和服装、背景的特色，组合起来自然具有中国味道。
第二，音乐体系的跨文化融合。作曲家吴祖强等人将西方管弦乐队与中国民族乐器（竹笛、琵琶、芦笙）相融合。更突破的是，该剧开创性地引入人声合唱，《娘子军连歌》和《万泉河水清又清》成为全剧的音乐灵魂。
第三，舞台美学的彻底革新。《红色娘子军》颠覆了古典芭蕾的叙事传统——不再有王子与公主，取而代之的是英姿飒爽的女战士；不再有白色纱裙，取而代之的是灰色军装、短裤和八角帽；刀枪首次作为道具出现在芭蕾舞台。

四、国际传播与经典化
《红色娘子军》的国际传播历程，是一部从政治符号到艺术经典的话语转换史。1972年尼克松访华时观看该剧，在回忆录中给予高度评价。1978年中国艺术团访美，现代舞宗师玛莎·格雷姆盛赞其非常有张力。2009年该剧首登巴黎歌剧院。2015年登陆纽约林肯中心，《纽约时报》称其为“一个革命性的舞台作品”，《经济学人》评价其“大步向前飞跃”。
截至2024年，该剧累计演出超过4000场，2019年入选中国艺术研究院发布的“在《讲话》精神照耀下百部文艺作品”榜单。

五、案例总结
芭蕾舞剧《红色娘子军》的成功实践，深刻印证了习近平文化思想中关于洋为中用、中西合璧的核心论述。
首先，洋为中用是文艺创新的重要路径。习近平在文艺工作座谈会上的讲话中指出：我们社会主义文艺要繁荣发展起来，必须认真学习借鉴世界各国人民创造的优秀文艺。只有坚持洋为中用、开拓创新，做到中西合璧、融会贯通，我国文艺才能更好发展繁荣起来。
其次，创造性转化和创新性发展是文艺创作的根本方法。习近平强调：传承中华文化，绝不是简单复古，也不是盲目排外，而是古为今用、洋为中用，辩证取舍、推陈出新。
最后，文化自信是开放创新的底气与根基。习近平强调：文化自信，是更基础、更广泛、更深厚的自信，是更基本、更深沉、更持久的力量。
《红色娘子军》跨越半个多世纪依然长演不衰，不仅是一部艺术经典，更成为中国文化走向世界的重要符号。
