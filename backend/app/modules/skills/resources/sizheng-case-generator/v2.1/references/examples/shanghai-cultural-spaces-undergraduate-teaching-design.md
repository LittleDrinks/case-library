# 把最好的资源留给人民
# ——上海文化新空间建设让城市成为艺术品
## ——本科生思政课教学设计

# 一、教学说明

## （一）教学目的

本案例以上海文化新空间建设为背景，讲解上海在"人民城市人民建，人民城市为人民"理念指引下，把最好的资源留给人民的城市实践。通过浦东美术馆"一排1座"的选址故事、"一江一河"滨水空间的贯通开放、"社会大美育"的惠民实践，引导学生理解习近平文化思想中的人民立场与文化观，理解"把最好的资源留给人民"的深刻意涵，认识城市不仅是居住的空间，更是文化的容器、精神的家园。引导学生增强文化自信与城市认同，自觉做人民城市建设参与者、城市文化生活的践行者。同时，本案例定位为上海大学案例，通过文学院院长刘旭光教授应邀主讲《看见人文之城》第六集的实例，让学生看到上大人以学问服务城市文化的真实身影，增强学校认同感与专业自豪感。

知识目标方面，了解上海文化新空间建设的基本事实与关键数据，理解人民城市理念、"以文化人"等核心概念。能力目标方面，学会用"物理空间、交往空间、精神空间"的视角观察和分析身边的文化空间，提升观察社会、分析问题的能力。价值目标方面，体认"把最好的资源留给人民"的价值追求，增强对人民城市理念的认同，激发参与城市文化生活的热情。

## （二）阅读思考题

1. 习近平总书记指出，"人民城市人民建，人民城市为人民"。结合浦东美术馆建在"一排1座"的故事，谈谈你对这句话的理解。

2. 小陆家嘴滨江核心区的那块"宝地"，多家开发商不惜重金也想拿下，上海却决定留下建美术馆。如果是你参与决策，你会怎样权衡？说说你的理由。

3. 前滩休闲公园的红砖步道用的是中粮仓库的旧砖。城市更新中保留旧物、活化遗存，有什么意义？

4. 你身边有哪些"家门口的文化新空间"？它们给你的生活带来了什么变化？

## （三）教学安排

本案例建议安排2课时（90分钟）。课前15分钟，学生预习案例材料，初步思考阅读思考题；第一课时（45分钟）为情境导入（10分钟）、案例剖析（20分钟）、理论解读（15分钟）；第二课时（45分钟）为分组讨论（20分钟）、汇报交流（15分钟）、总结升华与行动引领（10分钟）。

# 二、教学文本内容

## （一）导语

想象这样一个画面。黄浦江边，东方明珠脚下，陆家嘴最贵的一块土地上，矗立的不是又一栋写字楼，而是一座通体洁白的美术馆。周一的下午，别的美术馆大多闭馆，这里却人流如织；夜晚九点，加班归来的年轻人还在展厅里与百年前的油画对望。几公里外的江畔，孩子们踩着用老仓库旧砖铺成的红色步道追逐奔跑，老人坐在望江驿里翻书，江风掠过草坪。在《看见人文之城》系列短视频里，上海大学文学院院长刘旭光教授把这一切概括为一句话，让城市成为艺术品。城市怎样才能成为艺术品？这节课我们走进上海的文化新空间，寻找答案。

## （二）教学内容描述

### 1. 案例背景

黄浦江、苏州河是上海的母亲河，但两岸曾长期被码头、仓库、工厂占据，市民"看得见江，走不近江"。陆家嘴高楼林立、寸土寸金，却一度缺少人文气息。2019年11月，习近平总书记在上海考察时提出"人民城市人民建，人民城市为人民"。2024年2月，上海出台《上海市建设习近平文化思想最佳实践地行动方案》，部署九大行动、30项重点工程，文化新空间建设成为重要内容。

### 2. 面临的困难

一是黄金地块为谁而留的抉择。小陆家嘴最后一块滨江"宝地"，多家开发商不惜重金求地，建美术馆则意味着放弃巨额收益，还要投入超过13亿元建设资金。二是滨江岸线如何打通。黄浦江45公里岸线横跨5个区20个街镇，码头、仓库与"专用"岸线造成众多断点。三是文化空间如何"活"起来。场馆建好只是第一步，如何让普通市民特别是孩子都能亲近艺术，避免"有场馆、无内容"，是更大的考验。

### 3. 实践举措

第一，统一规划、整体营造，形成重大文化设施、区域文化活力中心、社区乡村商圈文化新空间的多层级格局。第二，把最好的资源留给人民。2021年7月8日，浦东美术馆在"一排1座"开馆，坚持周一不闭馆、夜场到晚九点。第三，还江于民。2017年年底黄浦江45公里贯通，2020年年底苏州河42公里贯通，如今"一江一河"贯通里程超过100公里；前滩休闲公园免费开放，红砖步道、望江驿、亲水平台人人可享。第四，让美育走进日常。143个"社会大美育课堂"年开展艺术普及活动8500多场、惠及580多万人次；浦东美术馆五年举办350余场公共教育活动，近2万名师生进馆上美育课。第五，以文化带动城市活力。浦东美术馆五年推出近30场重量级展览、累计参观人次近400万，"来上海看美展"成为城市新名片，看展带动周边餐饮、休闲、教育等行业发展。第六，上大人参与讲述。市委宣传部等单位出品的《看见人文之城》邀请知名社科专家解读行动方案部署的实践，上海大学文学院院长刘旭光教授应邀主讲第六集，把美学学问讲成了市民听得懂的城市故事。

### 4. 取得的成效

空间之变，"一江一河"贯通超100公里，滨江累计建成公共空间1200公顷；人气之聚，2024年度"一江一河"到访群众超过1.68亿人次；美育之效，"社会大美育课堂"年惠及580多万人次；品牌之势，上海7个门类11部作品获第十七届"五个一工程"奖，数量创历史新高。"浦美样本""一江一河实践""家门口的好去处"成为可推广的经验。

## （三）教学内容分析

### 【教学要点】

要点一，"把最好的资源留给人民"是人民城市理念的生动体现。城市最稀缺的资源是什么？是城市之心的土地，是滨水的岸线，是市民的时间与心灵。上海把这些最好的资源用来建美术馆、开滨江、办美育，说明人民城市建设的核心是把人的需要放在第一位。请同学们记住这个对比，一边是不惜重金的开发商，一边是留下来给老百姓建美术馆的定力。

要点二，文化新空间让"以文化人"落到实处。刘旭光教授说，文化新空间既是物理空间，又是交往空间，还是精神空间。物理空间是场馆和绿地，交往空间是人们在其中相遇、交流，精神空间是艺术与记忆对心灵的滋养。一个红砖步道既供人行走（物理），又让人驻足交谈（交往），还承载着中粮仓库的城市记忆（精神）。以此视角观察身边空间，你会发现城市处处有文化。

要点三，让城市成为艺术品，人民是欣赏者更是创造者。城市的艺术品格不在天际线的奇观，而在普通人的日常。孩子在沙坑里堆城堡，白领在夜校里学艺术，老人在望江驿看书，这些平凡场景的叠加，才让城市成为真正的艺术品。青年学生既享有城市文化空间，也应成为文化生活的参与者和创造者。

要点四，上大人在行动，学问可以服务城市。《看见人文之城》是为解读上海建设习近平文化思想最佳实践地而推出的官方系列短视频，文学院院长刘旭光教授作为美学学者应邀主讲第六集。他讲的不只是风景，更是城市为什么要把最好的资源留给人民的道理。把学问讲给市民听，本身就是参与人文之城建设的一种方式。同学们将来无论从事什么专业，都可以像这样把所学与社会需要连接起来，让自己的专业成为这座城市的一部分。

### 【教学过程】

本案例教学采用"情境导入—案例剖析—理论解读—研讨升华"四段式结构。

第一阶段（情境导入，10分钟）。播放《看见人文之城》第六集《让城市成为艺术品》片段，展示浦东美术馆"镜厅"映照江景、前滩休闲公园红砖步道、市民滨江生活的图片。抛出引导问题，"为什么说城市可以成为艺术品？上海把最贵的一块地留给美术馆，值不值？"激活学生的问题意识与生活经验，为案例学习奠定情感基础。

第二阶段（案例剖析，20分钟）。讲解案例背景、三重困难与六项举措，重点还原两个故事细节。一是"一排1座"的选址决策，多家开发商重金求地，上海决定"留下来给老百姓建美术馆"，并投入超13亿元、周一不闭馆、夜场到晚九点；二是"还江于民"的贯通攻坚，45公里岸线横跨5区20街镇，断点堵点众多，最终一一打通。通过数据与细节的展示，让学生把握"把最好的资源留给人民"如何从理念变为现实。

第三阶段（理论解读，15分钟）。紧扣案例内容，解读习近平文化思想的相关论述。重点阐释"人民城市人民建，人民城市为人民"的城市观、"把最好的资源留给人民"的价值观、"着眼满足人民群众多样化、多层次、多方面的精神文化需求"的供需观、"历史文化是城市的灵魂"的文脉观。引导学生理解，文化新空间建设不是简单的盖房子，而是城市发展价值观的深刻转变。

第四阶段（研讨升华，45分钟，含第二课时）。组织学生围绕思考讨论题分组讨论，每组聚焦一个核心问题，结合案例内容、理论知识与自身在上海的生活体验交流观点。各组代表汇报，教师点评。最后总结升华，强调人民城市理念的青春责任，引导学生从"打卡者"走向"参与者"，在日常生活中用好身边的文化空间，参与城市文化建设。

### 【教学方法】

1. 案例教学法。以上海文化新空间建设为案例，将习近平文化思想的核心论述与上海实践相结合，增强教学的生动性、针对性和说服力。

2. 问题导向法。围绕"为谁而留、为谁而开"的核心之问设计层层递进的思考题，引导学生带着问题学习，培养分析问题、解决问题的能力。

3. 小组研讨法。组织学生分组讨论、汇报交流，鼓励发表不同观点、相互启发，培养团队协作与表达能力，实现思想碰撞与认知升华。

4. 体验教学法。鼓励学生课后实地走访浦东美术馆、前滩休闲公园或身边的文化新空间，把课堂认知转化为切身体验，深化对"让城市成为艺术品"的理解。

## （四）思考讨论题

1. （理解类）"人民城市人民建，人民城市为人民"这句话中的两个"人民"分别是什么意思？结合案例说说你的理解。

2. （分析类）浦东美术馆坚持周一不闭馆、夜场开到晚九点。这些细节体现了怎样的办馆理念？从中可以看出城市公共文化服务应该怎样贴近人民？

3. （反思类）前滩休闲公园用老仓库的旧砖铺步道，有人觉得这是"念旧"，有人觉得这是"作秀"。你怎么看？城市记忆对一座城市意味着什么？

4. （践行类）请你为学校所在的街区设计一个"家门口的文化微空间"方案，说明选址、功能与活动设计，并解释它如何体现"把最好的资源留给人民"。

5. （反思类）刘旭光教授把美学研究讲成了市民听得懂的城市故事。你目前所学的专业，可以为城市文化建设做点什么？
