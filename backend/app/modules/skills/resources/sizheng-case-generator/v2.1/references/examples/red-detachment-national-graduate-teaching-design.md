# 芭蕾舞剧《红色娘子军》：理解洋为中用

一、教学目标
1. 知识目标
（1）掌握习近平文化思想中“洋为中用”“中西合璧”“融会贯通”等核心表述的内涵与出处。
（2）理解芭蕾舞剧《红色娘子军》的创制背景、艺术创新举措及国际传播历程。
（3）理解创造性转化与创新性发展在文艺创作中的具体机制。
（4）理解两个结合尤其是第二个结合在艺术领域的实践逻辑。
2. 能力目标
（1）能够运用“洋为中用”的理论视角，分析具体文艺作品的中西融合机制。
（2）能够辩证分析艺术创新过程中形式与内容、传统与现代、民族性与世界性的关系。
（3）能够结合案例，论述文化自信与开放学习之间的内在关联。
3. 价值目标
（1）深刻认同习近平文化思想关于文艺创新的科学论述，增强文化自觉和文化自信。
（2）理解“洋为中用”不是简单模仿，而是创造性转化和创新性发展，树立创新思维。
（3）感受《红色娘子军》所蕴含的红色精神和艺术匠心，培养对社会主义文艺的热爱与责任感。

二、课前准备
1. 硬件条件
多媒体教室（配备投影仪、音响等）、电脑、视频播放设备、网络（用于查阅案例补充资料）。
2. 软件与资料准备
教材：《习近平文化思想概论》（高等教育出版社 2024 年版）相关章节内容。
案例材料：《红色娘子军》案例文本、核心数据图表（演出场次、国际传播覆盖国家数等）、实景图片（舞台剧照、经典舞蹈动作等）。
视频资料：《红色娘子军》经典片段精选（5-8分钟，含经典舞蹈段落）。
3. 学生预习准备
预习教材相关章节，梳理习近平文化思想中关于文艺创新的核心论述，标注重点与疑问。观看《红色娘子军》经典片段，初步了解案例背景、艺术创新举措及国际传播历程。

三、教学对象
1.授课对象
一年级的硕士研究生
2.学情分析
（1）知识基础：已系统学习习近平文化思想相关基础理论，对文艺创新的核心理念有初步认知，但对“洋为中用”“中西合璧”的深层内涵、实践逻辑理解不够透彻。
（2）认知特点：具备一定的理论思辨能力和自主学习能力，关注社会现实问题，对艺术创新、文化自信等议题兴趣浓厚。
（3）学习需求：渴望将抽象理论与具体实践结合，通过鲜活案例深化对理论的理解。
（4）潜在不足：辩证思维有待加强，易片面看待借鉴与主体性、开放与保守的关系。

四、课程框架
1.理论重点
（1）洋为中用、中西合璧：艺术创新的根本路径。
（2）创造性转化、创新性发展：文艺创作的方法论。
（3）两个结合：更深层次的文化创造逻辑。
（4）文化自信：开放创新的底气与根基。
2.设计思路
本节课坚持理论引领、案例具象、问题导向、价值升华，以《红色娘子军》实践为典型样本，紧扣习近平文化思想核心理论，构建"理论—实践—理论"闭环教学。
3.总结点评要点
（1）理论契合度：点评学生是否能精准对接习近平文化思想四大理论要点。
（2）逻辑辩证性：点评学生是否能辩证分析洋为中用与全盘西化、文化自信与开放学习的区别。
（3）实践关联性：点评学生是否能从微观案例中提炼宏观理论逻辑。
（4）价值导向性：点评学生是否能深刻认同习近平文化思想的科学性。

五、课堂讨论问题
1. 习近平在文艺工作座谈会上指出："我们社会主义文艺要繁荣发展起来，必须认真学习借鉴世界各国人民创造的优秀文艺。只有坚持洋为中用、开拓创新，做到中西合璧、融会贯通，我国文艺才能更好发展繁荣起来。"结合《红色娘子军》的创作实践，谈谈你对这段话的理解。
2. 《红色娘子军》在舞蹈语汇上进行了哪些突破？这些突破如何体现了创造性转化、创新性发展的理念？
3. 《红色娘子军》走向国际舞台后，获得了来自美国、法国、古巴等不同文化背景观众和评论家的评价。这说明了什么？文化交流与文化传播需要遵循什么原则？
4. 有人说《红色娘子军》的成功在于坚守了文化主体性，也有人说它成功在于大胆借鉴了外来形式。你如何看待这两种说法的关系？

六、教学流程
（总时长：90 分钟）
1. 课程导入：情境引入，明确主题（10 分钟）
教学方法：情境导入法、设问法
主要内容：
（1）教师播放《红色娘子军》经典片段，展示娘子军穿足尖鞋、持大刀钢枪的舞台形象，与西方芭蕾白天鹅形象形成对比。
（2）设问导入："芭蕾这个舶来品，是如何变成讲述中国革命故事的载体的？这种混搭为什么能成功？"
（3）衔接教材：点明本节课核心是以《红色娘子军》为例，探究习近平文化思想中洋为中用、中西合璧的理论内涵与实践逻辑。
2. 案例展示：多维呈现，梳理脉络（15 分钟）
教学方法：视频教学法、图文讲解法
主要内容：
（1）播放《红色娘子军》精选片段（5分钟）。
（2）教师图文补充梳理：背景（1931年娘子军成立→1961年电影→1964年舞剧首演）→创新（舞蹈语汇、音乐体系、舞台美学三大突破）→传播（4000+场次、20+国家）→认可（尼克松、格雷姆、纽约时报评价）。
3. 案例剖析：理论对接，深度解读（25 分钟）
教学方法：问题导向法、理论联用法、启发式教学
主要内容：围绕四大理论要点，结合案例细节逐一剖析。
4. 小组讨论：协作探究，观点碰撞（25 分钟）
教学方法：小组讨论法、合作探究法
主要内容：围绕4个讨论问题开展深度讨论，每组推选汇报人依次汇报。
5. 总结升华：提炼逻辑，强化认知（15 分钟）
教学方法：归纳总结法、升华法
主要内容：点评各组汇报，提炼案例核心价值，回归习近平文化思想理论要点，强化文化自信。

七、教学反思与课后拓展
1. 教学反思
（1）教学亮点：案例选取典型鲜活，紧扣习近平文化思想理论要点；教学环节层层递进，注重学生主体性。
（2）潜在不足：案例信息量大，部分学生可能难以快速梳理核心脉络；课堂讨论时间有限。
（3）改进方向：课前制作核心要点清单；适当延长小组讨论时间。
2. 课后拓展
（1）撰写500字学习心得，结合教材梳理习近平文化思想中洋为中用、中西合璧的理论要点。
（2）调研身边的文艺创新案例，结合习近平文化思想分析其创新路径，撰写一篇小论文，不少于2000字。
（3）关注习近平文化思想最新论述，思考文艺创新对本专业的启示。
