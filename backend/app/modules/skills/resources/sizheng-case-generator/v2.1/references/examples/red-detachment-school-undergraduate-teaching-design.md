# 芭蕾舞剧《红色娘子军》：理解洋为中用

一、教学说明
（一）教学目的
本案例以芭蕾舞剧《红色娘子军》的创作为分析样本，阐述该剧如何以西方芭蕾艺术形式成功讲述中国革命故事，引导学生理解习近平文化思想中洋为中用、中西合璧的核心要义。通过案例学习，增强学生的文化自信，树立开放包容的创新意识。
1. 知识目标
（1）理解洋为中用、中西合璧的基本内涵。
（2）了解芭蕾舞剧《红色娘子军》的创作背景和主要艺术创新举措。
（3）了解该剧的国际传播历程和经典地位。
2. 能力目标
（1）能够结合案例，理解洋为中用与全盘西化的区别。
（2）能够分析具体艺术作品的中西融合机制。
（3）能够论述文化自信与开放学习之间的关系。
3. 价值目标
（1）深刻认同习近平文化思想关于文艺创新的科学论述，增强文化自信。
（2）理解洋为中用不是简单模仿，而是创造性转化和创新性发展。
（3）感受《红色娘子军》所蕴含的红色精神和艺术匠心。

（二）阅读思考题
1. 习近平指出：我们社会主义文艺要繁荣发展起来，必须认真学习借鉴世界各国人民创造的优秀文艺。只有坚持洋为中用、开拓创新，做到中西合璧、融会贯通，我国文艺才能更好发展繁荣起来。结合《红色娘子军》的创作实践，谈谈你对这段话的理解。
2. 《红色娘子军》在舞蹈语汇上进行了哪些创新？这些创新如何体现了创造性转化的理念？
3. 《红色娘子军》走向国际舞台后获得了广泛赞誉。这说明了什么？文化交流需要注意什么？
4. 结合案例，谈谈青年学生应如何理解和践行文化自信？
（三）教学安排
本案例建议安排2课时（90分钟）。课前15分钟，学生预习案例材料；第一课时（45分钟）：情境导入（10分钟）、案例系统呈现（20分钟）、理论解读（15分钟）；第二课时（45分钟）：分组讨论（20分钟）、各组汇报交流（15分钟）、总结升华（10分钟）。

二、教学文本内容
（一）导语
芭蕾舞，这门被誉为"脚尖上的艺术"的西方古典舞蹈，在数百年的发展中形成了王子与公主的叙事传统和优雅柔美的审美范式。但当它遇上中国革命故事，会发生怎样的化学反应？
1964年9月26日，北京天桥剧场，一场前所未有的艺术实验拉开帷幕——芭蕾舞剧《红色娘子军》首演。一群头戴五星八角帽、身披戎装的女战士，穿着足尖鞋，手持大刀钢枪，在芭蕾舞台上破天荒地上演了中国土地革命战争的壮烈史诗。
60年来，这部作品累计演出超过4000场，足迹遍布20多个国家，2015年登上纽约林肯中心的舞台。它不仅是我国芭蕾史上的里程碑之作，更是习近平文化思想中洋为中用、中西合璧理念的生动实践。

（二）教学内容描述
1. 创作缘起与历史背景
芭蕾舞剧《红色娘子军》的故事原型，来自1931年5月1日在中国海南岛成立的中国工农红军第二独立师第三团女子军特务连。这支由百余名女战士组成的队伍，在琼崖大地上进行了艰苦卓绝的革命斗争，被誉为"妇女解放运动之旗帜"。1961年，梁信创作电影文学剧本《红色娘子军》，1962年谢晋将其搬上银幕，获得首届百花奖最佳故事片等多项大奖，红遍全国。
1963年底，周恩来总理在观看中央芭蕾舞团演出的《巴黎圣母院》后，提出"你们可以一边学习排演外国的古典芭蕾舞剧，一边创作一些革命题材的剧目"。这一指示直接促成了《红色娘子军》芭蕾舞剧的创作。1964年2月，创作班子奔赴海南岛深入生活，采访当年娘子军连的老战士，探访老革命根据地，搜集音乐舞蹈素材。同年9月26日，《红色娘子军》在北京天桥剧场首演。1964年10月8日，毛泽东主席观看后题词："革命是成功的，方向是对头的，艺术上也是好的。"
2. 艺术创新的突破性举措
《红色娘子军》的艺术创新，体现在舞蹈语汇、音乐体系、舞台美学三个层面。
舞蹈语汇上，编导蒋祖慧创造性地融合了多种艺术传统。琼花的倒踢紫金冠和串翻身突破古典芭蕾的柔美程式，融入中国古典舞的技巧张力；娘子军的大刀舞吸收了中国武术武舞的元素，刚劲有力；赤卫队的五寸刀舞借鉴了广东英歌舞的节奏韵律。蒋祖慧总结道：以芭蕾为主，尽量充分地运用芭蕾语汇，同时积极吸收本土特色，再加上中国民间韵律和服装、背景的特色，组合起来自然具有中国味道。
音乐体系上，作曲家吴祖强等人将西方管弦乐队与中国民族乐器（竹笛、琵琶、芦笙）相融合，创造出既具交响性又富民族特色的音响效果。更突破的是，该剧开创性地在芭蕾中融入人声合唱，《娘子军连歌》和《万泉河水清又清》成为全剧的音乐灵魂。
舞台美学上，《红色娘子军》颠覆了古典芭蕾的叙事传统——不再有王子与公主，取而代之的是英姿飒爽的女战士；不再有白色纱裙，取而代之的是灰色军装、短裤和八角帽；刀枪首次作为道具出现在芭蕾舞台。
3. 国际传播与经典化
《红色娘子军》的国际传播历程，是一部从"政治符号"到"艺术经典"的话语转换史。1972年尼克松访华时观看该剧，在回忆录中评价：它那令人眼花缭乱的精湛表演艺术和技巧给了我深刻的印象。1978年中国艺术团访美，现代舞宗师玛莎·格雷姆盛赞其非常有张力。2009年该剧首登巴黎歌剧院，法国观众评价其看懂了一个故事，了解了一段中国历史。2015年登陆纽约林肯中心，《纽约时报》称其为：一个革命性的舞台作品。
截至2024年，该剧累计演出超过4000场，足迹遍布20多个国家。

（三）教学内容分析
【教学要点】
要点一：洋为中用是文艺创新的重要路径。习近平在文艺工作座谈会上的讲话中指出：我们社会主义文艺要繁荣发展起来，必须认真学习借鉴世界各国人民创造的优秀文艺。只有坚持洋为中用、开拓创新，做到中西合璧、融会贯通，我国文艺才能更好发展繁荣起来。《红色娘子军》正是这一论断的生动实践。
要点二：创造性转化和创新性发展是文艺创作的根本方法。习近平强调：传承中华文化，绝不是简单复古，也不是盲目排外，而是古为今用、洋为中用，辩证取舍、推陈出新。《红色娘子军》对芭蕾的改造不是简单替换，而是创造性转化。
要点三：文化自信是开放创新的底气与根基。习近平指出：文化自信，是更基础、更广泛、更深厚的自信。《红色娘子军》的成功，根本上源于创作者对自身文化的深厚自信。
【教学过程】
本案例教学采用"情境导入—案例剖析—理论解读—研讨升华"四段式结构。第一阶段（情境导入，10分钟）：播放《红色娘子军》经典片段，展示娘子军穿足尖鞋、持大刀钢枪的舞台形象，与西方芭蕾白天鹅形象形成对比。抛出引导问题：芭蕾这一舶来品，是如何变成讲述中国革命故事的载体的？
第二阶段（案例剖析，20分钟）：讲解《红色娘子军》的创作背景、艺术创新举措。重点讲解舞蹈语汇、音乐体系、舞台美学三个层面的创新实践，让学生理解中西合璧不是简单的元素叠加。
第三阶段（理论解读，15分钟）：紧扣案例内容，深入解读习近平文化思想的相关论述，重点阐释"洋为中用""创造性转化""文化自信"等核心概念。
第四阶段（研讨升华，分组讨论+汇报+总结）：组织学生围绕思考题展开分组讨论，每组聚焦一个核心问题。教师总结案例，引导学生树立文化自信，理解开放包容与创新发展的内在逻辑。
【教学方法】
1. 案例教学法：以《红色娘子军》为典型案例，将习近平文化思想与具体艺术实践相结合。
2. 问题导向法：围绕教学目标设计思考题，引导学生带着问题学习、思考、讨论。
3. 小组研讨法：组织学生分组讨论、汇报交流，鼓励学生发表不同观点。
4. 视听教学法：运用《红色娘子军》经典片段视频，增强学生的直观感受。

（四）思考讨论题
1. 《红色娘子军》将芭蕾这一西方艺术形式与中国革命故事相结合，你如何理解"洋为中用"的真正含义？
2. 蒋祖慧说："以芭蕾为主，尽量充分地运用芭蕾语汇，同时积极吸收本土特色，再加上中国民间韵律和服装、背景的特色，组合起来自然具有中国味道。"这段话对你理解"中西合璧"有什么启发？
3. 《红色娘子军》在国际传播中获得了广泛赞誉。你认为在进行文化交流时，应该如何处理民族特色与世界通约性的关系？
4. 结合案例，谈谈青年学生应如何理解和践行文化自信？
