# 单段修订工作流 v2.1

围绕作者指出的一个目标段落完成一次修订建议：

1. 确定目标段落：正文段落按出现顺序从 0 开始编号，作者说「第 N 段」时目标编号为 N-1。
2. 调用 `search_corpus` 检索与目标段落主题相关的平台资料；只采信工具返回的来源。
3. 调用 `propose_revision`：给出目标段落编号、替换后的完整段落文本和修改理由。替换文本必须保持原段落的教学语义，引用资料事实但不编造出处。
4. 候选提交后等待作者决定，不重复提议同一段落。

只处理一个段落；作者要求修改多处时，说明本工作流一次只处理一段。
